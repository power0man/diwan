# ربط الأدوات الاختياري — ٤ أكتوبر ٢٠٢٦

هذا ربط داخل شيفرة ديوان، اختياري وغير منشور في الإنتاج. يبقى مسار الواجهة والسحابة للفرق المخصصة لهما. القرار التنفيذي هو أمر حسين المباشر بإكمال مراحل التوظيف، ولا يُضاف قرار في DECISIONS.

## المراقبة عند حد المزوّد

`ChatSession(..., observer=...)` و`AgentSession(..., observer=...)` يمرّران فقط نداءات `provider.complete` الجديدة إلى محوّل المراقبة. لا تتغير بيانات الجلسة المحفوظة أو بصماتها، ولا تُولّد إعادة العرض/الاستئناف المكتمل نداءً أو span جديدًا. بلا observer يُعاد المزوّد نفسه ولا تُحمّل SDK. تظل سياسة المزود المحلي قائمة.

```python
from conversation.observability import LocalLangfuseObserver
from conversation.session import ChatSession
observer = LocalLangfuseObserver(capacity=128)
session = ChatSession(root, "session", model=model, model_version=version, observer=observer)
try:
    result = session.turn("turn", message, provider)
    metadata = observer.snapshot()
finally:
    observer.close()
```

تُثبت `langfuse==4.16.0` في بيئة اختيارية منفصلة؛ ليست اعتمادًا لازمًا للتطبيق. نسخة SDK المجرّبة وقفل تبعياتها في تسليم التشغيل المحلي. يبدأ المحوّل بمصدّر RAM محدود فقط، بمفاتيح وهمية ثابتة النوع وendpoint غير مستخدم على127.0.0.1:1. لا جلب prompts أو تشغيل experiments أو تصدير لخادم. لا يعني هذا dashboard أو تخزينًا دائمًا.

الحقول الوحيدة: `duration_ms/model/error_code/input_tokens/output_tokens`. هويات النموذج ورموز الخطأ قوائم مغلقة؛ القيم المجهولة لا تمر حرفيًا. أعداد التوكن المفقودة/غير الصالحة `None` وليست صفرًا مقيسًا. النصوص، thinking، المخرجات، الاستثناءات، الهويات، الإيصالات، المسارات، والاعتماد لا تدخل أحداث المراقبة. مصدر العدد Usage من رد المزوّد وليس tokenizer مستقلًا. الزمن زمن complete وحده؛ رفض القبول أو فشل estimate أو حكم تحقق النواة ليس ضمن هذا الرقم، ونجاح النقل لا يثبت صحة الجواب.

يُحفظ الناتج والاستثناء الأصلي عند فشل observer العادي وتجهيز metadata. لا تُضمن مهلة callback معلق أو exactly-once للأحداث بعد موت العملية؛ collector محلي موثوق وليس sandbox لكود callback عدائي. الحفظ في الجلسة والإيصال أقوى من مراقبة best-effort.

## MCP بأداة عامة واحدة وإيصال ديوان

`PublicMCPBridge` يتطلب دليل لقطة عامّة مغلقًا، خارج مخزن الإيصالات، وبيانًا موثوقًا بهذا الشكل:

```json
{"data_policy":"public","files":{"vision.md":"<64 lowercase hex SHA256>"}}
```

المشغّل يجهز اللقطة العامة؛ هذا التصنيف لا يُستنتج من الاسم ولا يسمح بنقل بيانات المالك. الأسماء محددة، من1 إلى8 ملفات، كل ملف UTF-8 عادي بلا روابط وبحد12000 بايت، والبصمة مثبتة. عنصر إضافي في الدليل أو تغير أي ملف يرفض اللقطة قبل أن يأخذ ActionStore صورة لها. لا توجّه هذا المدخل إلى مساحة مالك أو checkout خاص؛ يستعمل في القبول ملفات عامة مصطنعة فقط.

```sh
python tools/serve_public_mcp.py --public-root PUBLIC_SNAPSHOT --state-root PRIVATE_RECEIPTS --manifest MANIFEST.json
```

تُثبت `mcp==2.3.0` اختيارياً. النقل stdio فقط؛ لا HTTP أو daemon أو اكتشاف خوادم أو صلاحيات اعتماد. الأداة الخارجية الوحيدة `read_public_file(request_id,name)` تقابل عقد `read_file` بدرجة auto. تمر عبر ToolRegistry وregister_step وinvoke_prepared في ActionStore، وحجر النص يسبق الإيصال. نفس request_id يعيد الإيصال، وتغيير الملف بنفس الهوية يرفض؛ إيصال مفقود لا يبيح إعادة التنفيذ. لا owner consent أو كتابة أو تنفيذ أو اختيار مسار خارج البيان. طلبات الرفض لا تكشف استثناء المضيف أو مساراته. موارد MCP السابقة بقيت مختبرًا منفصلاً؛ هذه الجولة تضيف أداة محددة فوق عقود ديوان.

## القبول وحدوده

معيار هذه المرحلة100% للحالات المحددة دون تسرب canary أو تجاوز إذن أو إعادة نداء. وهو معيار تركيب/حراسة، لا نسبة جودة نموذج أو ضمان تعميم. القياس الأول:27 اختبارًا مضافًا، و143 اختبارًا مركّزًا مع الجلسات القائمة؛18 مجسًا ناجحًا على Langfuse وعميل/خادم MCP حقيقيين تحت رفض شبكة OS. أضافت مراجعة المصدر حارس ترميز لكل ملفات البيان قبل أخذ أي لقطة أو إنشاء إيصال: الحالة الجديدة فشلت على7e30340، ثم أُصلح الحارس وأضيفت طفرة له؛ أصبح المضاف28 اختبارًا. تُحفظ نتيجة الرأس المعدّل مستقلة في تسليم utf8-fix، ولا تُنسب له نتيجة الرأس السابق. لا نداء نموذج أو بيانات مالك. الطفرات والشامل والبوابات تُنسب إلى الرأس المقيس في التسليم، ولا تُفترض من هذه الأرقام.

الـSDK الحقيقي كشف عند الربط أن scalar metadata لا يأتي دائمًا JSON وأن dict المجرد ليس structuredContent افتراضيًا؛ صُحح التطبيع وصُرّح structured_output. رفض MCP يأتي protocol error في بعض الحالات، وتأكد المجس من الرمز الفعلي لا timeout. الأدلة السابقة والفشل التشخيصي محفوظة؛ لم تخفف حدود القبول لتجاوزها.
