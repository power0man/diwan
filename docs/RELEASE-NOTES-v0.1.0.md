# ديوان v0.1.0 — «ديوان على جهازك»

> **الحالة:** إصدار (ك٢٨). فحصُ الدخان الحيّ على جهاز المالك (ماك، ٢٥ سبتمبر ٢٠٢٦) بالمحرّك `qwen3.5:9b`
> والمتن الموضوع: **الخطواتُ الستّ `ok` والخروج 0** (§٤ أدناه، والملف `docs/probe/launch-check-mac-20260925.json`).
> بوابةُ الخطة §١.٣ مستوفاة، والوسمُ `v0.1.0` على إيداع الدمج.

## ١ — ما هو

ديوان مساعدٌ عام محوره العربية يعمل على جهازك بمحرّكٍ محلي عبر Ollama وبواجهةٍ محلية: يحادث ويكتب ويبرمج
ويعمل على الملفات بالأدوات في حلقةٍ محكومة (درجاتُ إذن، ودفترُ رجوع، وإيصالاتُ أفعال)، ويحجر النصَّ
الخارجي قبل أن يبلغ النموذج، ويستخرج الجذور بـCAMeL Tools، ويسترجع من ملفاتك بـBM25 ومتّجهات، ويبحث في
الويب محكومًا. وعقدةُ السياسات (المتنُ البحري) تعمل حيث يضع صاحبُها متونَه محليًّا (`tools/place_private_stores.py`).

**الرخصة:** Apache-2.0 (ق٥١). **المستودع:** `power0man/diwan` (ق٥٢).

## ٢ — التشغيل

كما في `README.md`: `uv sync --extra morphology` ← `uv run camel_data -i morphology-db-msa-r13` ←
`ollama pull qwen3.5:9b` ← `uv run python tools/launch_check.py` ← `uv run python tools/serve_ui.py`.

**المحرّكُ المعتمَد:** `qwen3.5:9b` (ق٥٤) بالقياس على عيّنةٍ طبقيّة من بنك Kimi: ٥٤٫٣٪ مقابل ٤٨٫١٪ لـ`qwen3:14b`
و٤٥٫٢٪ لـgemma4 (`docs/probe/k2-engine-comparison-20260925.json`). **الجذور:** CAMeL باتّفاق التحليلات ٨٣/١٠٠
بخطأين، والقالبيُّ احتياطيٌّ مسمًّى ٦١/١٠٠ (`docs/probe/g1-camel-vs-morphology-20260925.json`، ق٥٥).

## ٣ — الحدودُ المعلَنة (ما لم يُجرَّب حيًّا أو لم يُقَس)

| ما | حالُه في v0.1 |
|---|---|
| التنفيذُ المعزول ونجاحُ المهام الوكيلة في Docker (ك١٣، ج٣) | مبنيٌّ ومُثبَت بالاختبار؛ **لم يُجرَّب حيًّا** على جهازٍ فيه Docker |
| البحثُ في الويب (ج٢) | مبنيٌّ ومُثبَت؛ **لم يُجرَّب على SearXNG حيّ** |
| الاسترجاعُ بالمتجهات (غ٢) | المسارُ مبنيّ؛ **الرقمُ الدلاليُّ لم يُقَس** |
| رقمُ م١٤ | منشورٌ بـ`qwen3:14b` وبمقياسٍ صُحّح بعده (ك٢١)؛ **يُعاد على المحرّك المعتمَد** (ك٣٢) |
| بنكُ Kimi | عيّنة ٢٠٪ بنداءٍ واحد؛ فحوصُ `contains` قابلةٌ للتلاعب في شطرها (ك١٧، مؤجَّلة بعد الإطلاق) |
| فحصُ `exact` | صارمٌ بقرار (ق٥٧)؛ يُنشر الرقمان معًا |
| CAMeL على مستوى pip | في `--extra morphology` حتى يُقفل torch للمعالج (ك٣٣) |
| الحَجر | يُضيّق السطح ولا يُغلقه: سبعُ صورِ تجاوزٍ معلَنةٌ باسمها في `tests/test_quarantine_declared_limits.py` |
| العزل | نظافةُ مفسِّر لا حدٌّ أمني؛ الحدُّ المضيفُ الزائل المعلَن (ق٤٤) |
| فحصُ الدخان على ماك | التشغيلُ الأول سقط (`unsafe_path`): المؤقّت تحت `/var` رابطٌ إلى `/private/var` — عطبُ ك٨ نفسُه؛ أُصلح بحلّ المسار في `tools/launch_check.py` مع اختبار، والناتجُ أدناه من تشغيلٍ ثانٍ بـ`TMPDIR` بلا رابط قبل الإصلاح |
