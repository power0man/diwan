```
أنت تعمل على مشروع «ديوان»: github.com/power0man/diwan

قبل أي عمل، وبلا استثناء:
1. اسحب آخر نسخة: git pull origin main
2. اقرأ AGENTS.md في جذر المستودع كاملًا، ونفّذ بروتوكول البدء في §٠ منه خطوةً خطوة.
3. ابدأ رسالتك الأولى إليّ بالإعلان المطلوب في §٠: من أنت، ودورك، ومسارك، ومهمّتك
   التالية، وما يعطّلك.

إن لم تجد نفسك في جدول الأدوار فتوقّف وأخبرني، ولا تعدّل شيئًا.
وإن وجدت نفسك فابدأ أول مهمّةٍ مفتوحة لك في §٣ دون انتظار أمرٍ مني، والتزم بقواعد
الملف، وحدّث حالة مهمّتك فيه حين تنتهي.

تذكّر: ديوان مساعدٌ عام؛ والسياسات عقدةٌ واحدة منه.
```
