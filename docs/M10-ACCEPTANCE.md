# م١٠ — الملفات والتفضيلات والأدوات المحلية المحدودة

**٢١ سبتمبر ٢٠٢٦ — ق٣١.** إنجاز تقني تجريبي، مع بقاء م٨-ب والحكم
البشري على جودة المساعد معلقين. دليل الاستخدام `WORKSPACE.md`.

## النطاق المنفذ

`TextWorkspace` يقرأ ملفات UTF-8 مختارة بحد 64KiB داخل جذر صريح،
ويمنع الروابط والعبور والملفات غير العادية. يفتح مكونات المسار عبر
مقابض مجلدات دون اتباع روابط، ويحفظ النص وبصمته وقياسه دون تحويله
إلى تعليمات تنفيذ أو مصدر معرفي معتمد.

`Preferences` يحفظ لغة الجواب وطوله واسم المخاطبة فقط، بتعديل صريح
ونسخة متوقعة تمنع فقد التحديثات المتزامنة. لا يستنتج تفضيلًا من
المحادثة أو محتوى الملف. `validate_snapshot` يفحص العقد والبصمة
دون قراءة ملفات. الحالة خاصة ومكتوبة ذريًا تحت قفل.

`AssistantWorkspace` يميز طلب المستخدم والملفات غير الموثوقة
والتفضيلات في سياق JSON مغلق. تمر الجولة عبر محادثة م٩ وحلقتها
المحكومة. إعادة العرض تستعمل النسخة المجمدة بلا فتح ملف المصدر أو
تفضيلات اليوم، وتعمل حتى بعد حذف مجلد المصدر.

الكتابة أداة صريحة: اقتراح قابل للمراجعة، ثم تطبيق بهوية الاقتراح
وبصمة المحتوى، إلى ملف جديد فقط. لا shell ولا تعديل ملف موجود ولا
تنفيذ مستقل للنموذج. يثبت إيصال الإنشاء قبل المحتوى؛ تعافي الانقطاع
يتحقق من الملكية والبصمة ولا يتبنى ملفًا سابقًا أو يعيد فعلًا مجهولًا.

  التطبيق المطابق وإعادة عرضه، ورفض الاستبدال أو تغيير حمولة الطلب.
- **13/13 قبول حي محدود**: ملف اختبار مصطنع واحد، ونداء محادثة واحد
  ونداءا metadata، ثم إعادة جواب مطابق بعد حذف المصدر بلا اتصالات
  جديدة أو تغيير حالة. التشغيل `m10-first-20260921`.

الملف المصطنع ذكر لقاء «مراجعة ديوان»، الثلاثاء الساعة العاشرة،
لمراجعة قائمة المهام. كان الجواب الفعلي:

> الملاحظة المرفقة تشير إلى لقاء مقرر يوم الثلاثاء الساعة العاشرة بعنوان "مراجعة ديوان" والمطلوب خلاله مراجعة قائمة المهام.

الاستهلاك المبلغ 534 توكن إدخال و43 إخراج، والكلفة المالية المحلية
صفر وفق عقد المزود. لا يعني ذلك انعدام استهلاك الجهاز أو تعميم جودة
التلخيص. عُرض الجواب كاقتراح ملف ثم طُبق في مجلد اختبار فقط؛ طابقت
البايتات والبصمة المسودة، ولم تغيّر إعادة التطبيق الملف أو وقت
تعديله. كان التطبيق استدعاءً صريحًا من مشغّل الاختبار، **لا إقرار
مراجعة بشرية**. لم تُقرأ أو تُعدل وثائق شخصية للمستخدم.

## التدقيق والإصلاح

ثلاث مراجعات مستقلة ومفنّدان لكل عيب مثبت؛ أُغلقت هذه الحالات:

| المشكلة | السبب والإصلاح |
|---|---|
| إعادة العرض مرتبطة بمجلد المصدر، وجذور القراءة المختلفة تتعارض مع مخرجات مشتركة | فصل عمر بيانات القراءة عن مخزن الكتابة؛ إعادة العرض لا تنشئ أداة ملفات، وعمليات المخرجات لا تفتح المصدر |
| رفض محارف تنسيق العربية الصحيحة | كان الحارس يعد كل فئات Unicode C بيانات ثنائية؛ ضُيق الرفض إلى محارف التحكم الفعلية مع بقاء UTF-8 صارمًا وحفظ RLM وZWJ كما وردا |
| حالة مقترحات صحيحة تصبح غير قابلة للقراءة عند الحد الأعلى | 256 نصًا بحجم 64KiB مع هروب JSON تتجاوز 32MiB؛ رُفع حد قراءة الحالة إلى 64MiB واختُبر الحد الفعلي |
| تبديل جذر التفضيلات بين فحص المسار وفتحه | أصبح القفل والقراءة والكتابة والاستبدال عبر مقابض مجلدات مثبتة وبدون اتباع روابط؛ محاولتا سباق مستقلتان لم تمسا المخزن البديل |

## الحدود المتبقية

صلاحية API تعود إلى مستدعيه؛ تطابق البصمة عملية تطبيق صريحة، وليس
مصادقة هوية بشرية. النموذج لا يملك أدوات هذه الواجهة ولا يطلق
تطبيقًا أو تغيير تفضيلات من جوابه. هذا يمنع الآثار البرمجية غير
المطلوبة، لكنه لا يثبت مقاومة حقن التعليمات في دلالة الجواب؛ النص
قد يظل مضللًا أو خاطئًا ويحتاج مراجعة.

تُحفظ البيانات محليًا دون تشفير داخل حساب المالك. إعادة كتابة
الملفات والحالة وإيصالاتها معًا أو إعادة نسخة قديمة خارج كشف البصمات.
لا استخراج PDF/Word أو صور، ولا توصيل أدوات خارجية أو تنفيذ شيفرة،
ولا تعلم تلقائي أو تدريب أوزان. حد السياق المشترك قد يرفض ملفًا
مسموح الحجم منفردًا، وهو رفض معلن قبل النداء.

م١١ هي واجهة الاستخدام اليومي وتجربة مهام المالك؛ لا يثبتها هذا
الاختبار المصطنع. `quality_pending=true` و`release_ready=false`
باقيان، ولا تُستبدل بهما بوابة م٨ المستقلة أو مراجعة الاستخدام.
