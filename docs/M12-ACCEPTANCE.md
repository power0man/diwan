# م١٢ — إدخال صورة وصوت محليين، نطاق تجريبي

**٢١ سبتمبر ٢٠٢٦، ق٣٣.** أُنجز مسار الإدخال وإجابة نصية، CLI وواجهة.
لا اعتماد جودة عام أو إغلاق بشري لم٨-ب؛ `release_ready=false`.
التشغيل والحدود التفصيلية في `MEDIA.md`.

## العقد والموارد

PNG محدود أو WAV PCM حتى 8 ثوان، باختيار صريح. تدخل البايتات الكاملة
والنوع والاسم والبصمة والوصف والسياسة ولقطة التفضيلات في Request
المحكوم. لا يتغير عقد Message القديم أو بصمات الجلسات النصية؛ نظام
مختلف يميز جلسة الوسائط. يتلقى المزود المحلي البايتات بعد التحقق.
لا استخراج عام أو OCR مضمون أو توليد صوت وصور في هذه الدفعة.

فُحصت الموارد المثبتة: خمسة تسجيلات محلية وواحد يستبعد لوجود
metadata بعيدة، ومورد محلي قائم يدعم completion/vision/audio؛ حجمه
9,608,350,718 بايت. ذاكرة الجهاز 24 GiB. لم يُنزّل نموذج أو صوت ولم
تُغيّر خدمة أو إعداد تشغيل للمضيف. النقل مثبت على Ollama 0.34.2؛
يُرفض تغير النسخة إلى أن يفحص عقدها. سياق التنفيذ 8192، والإجابة
حتى 400 وحدة، والمهلة 180 ثانية. الهوية الفعلية تبقى في الدليل الخاص.

أربعة وسائط و524288 بايت حد الطلب المتراكم، و32 جولة و4 MiB حد
نصوص المدخلات المحفوظة لكل جلسة. قبول الحصة داخل قفل الجولة بعد
إتاحة استرجاع القديم، وقبل حفظ pending أو نداء المزود.

وليست فصلًا لكلفة كل وسيط أو إثباتًا لفك جميع المدخلات. لا قياس كمون

الدليل العام المصفى في `probe/m12-media-20260921.json`؛ الخاص يحفظ

كان الإجمالي طلبَي توليد وستة metadata (نسخة، قائمة، وصف لكل طلب).
بعد حذف مجلد مصادر الاختبار وإعادة فتح الجلسات، استُرجعت النتيجتان
وبايتهما الأصلية دون مزود أو تفضيلات حالية أو اتصال جديد. ملف الصوت
الذي اختاره المشغل لم يُغيّر. حُفظت بايتات الحالة؛ mtime لسجل القراءة
ليس ضمانًا في عقد الاسترجاع الحالي.

## التدقيق الثلاثي والتفنيد

A: الخدمة وCLI والمزود؛ B: عقد الوسائط وسلامة الجلسة والحدود؛
C: HTTP والواجهة والقبول. لكل عيب مؤكد مفندان مستقلان قبل إغلاقه.

| العيب | السبب والأثر | الإصلاح والدليل |
|---|---|---|
| B1 / A1 | حصة الوسائط فُحصت قبل قفل الجلسة؛ طلبان يقرآن 31 جولة ثم ينفذان بالتتابع يبلغان 33. ظهر أيضًا تجاوز حقيقي إلى 4,232,542 بايت فوق 4 MiB | فحص الحصتين بالحالة الطازجة داخل قفل ChatSession بعد replay وقبل pending. قبول واحد ورفض الثاني بـmedia_session_limit، دون زيادة نداءات المزود؛ أعاد المدققون اختبارات الحدين |
| C1 | مفتاح رسالة الواجهة خالف رمز رفض نسخة المزود فأظهر شرحًا عامًا | مطابقة local_media_runtime_unsupported وفحص JS للشرح العربي الخاص؛ الرفض نفسه لم يكن معطلًا |

تحققت كذلك استعادة pending بوجود/غياب نتيجة في السجل بلا إعادة
المزود، ومنع خلط أنواع الجلسات أو المشروعات، ورفض البايتات المشوهة
قبل إرسالها، واختيار ملف متأخر بعد الانتقال، وبقاء مسودة/ملف جديدين
عند وصول جواب قديم، وإلغاء روابط معاينة الوسائط عند الإغلاق والتنقل.

## ما لم تثبته هذه المرحلة

- بنك صور وصوت مستقل، كلام بشري طبيعي ولهجات وضوضاء، أو دقة OCR.
- مقاومة الحقن الدلالي أو صحة أي جواب عام؛ المخرجات `unverified`.
- حكم بشري، عرض بصري للمتصفح، تشغيل WebMCP في متصفح داعم، أو زمن
  مراجعة المالك. لا تُملأ هذه النتائج آليًا باسم المالك.
- استقلال ديوان بأوزان نموذج أو تعلم دائم من البيانات؛ القدرة من
  المورد المثبت، فوق نواة التحكم الخاصة بالمشروع.
- حقوق نشر المصادر، نشر عام، خدمة دائمة، أو إغلاق م١٣. ينبغي حسم
  حالة استخدام التوسع ومنفعتها والحقوق والجودة قبل اعتمادها.
