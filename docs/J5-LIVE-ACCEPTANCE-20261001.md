# ج٥ — دليل التنفيذ والبحث، ١ أكتوبر ٢٠٢٦

اجتاز التنفيذ في Docker والبحث الفعلي عبر الواجهة فحوصًا مصطنعة محددة. الدليل العام
[`probe/j5-docker-searxng-20261001.json`](probe/j5-docker-searxng-20261001.json)
يفصل نتيجة التشغيل عن قبول جودة النموذج.

## ما أُعيد فحصه

على المصدر `a1bac4eef0e6defea7b2248db95047efda45ad3f` شُغّل المجس القائم
`tools/probe_execution_boundary.py` دون تعديل. نجحت الحالات الست: عزلة المستخدم
والتركيب والشبكة، وعدم اعتبار stdout المزور حكمًا، وانتهاء مهلة العملية وأبنائها،
ورفض نتيجة تنفيذ غير متحققة أو إيصال تشغيل غير مطابق. تحقق التنظيف بمعرّفات
الحاويات ولم تبق حاوية من المجس. وفي `core/sandbox.py` نجح البرنامج الصحيح،
وسقط الخاطئ، ورُفض خروج صفر قبل المدقق بالرمز `verdict_missing`.

وفي الإصدار المنشور `3ebd96eac0c50f1501e8a2bbc2888b639a5ae217` جرى فحص
متصفح بعد تسجيل الدخول، بأربع جولات مصطنعة مكتملة:

- محادثة حسابية أعادت 56.
- `analyze_data` أنشأت داخل Docker ملف CSV ذا قيمة 5، وتحققت بصمته.
- ظهرت موافقة محددة على `python3 -c "print(6*7)"`، ثم نفذت الأداة داخل Docker
  وأعادت 42 وخروج صفر. وافق مشغّل Codex ضمن تفويض المالك؛ ليست هذه تجربة استخدام بشرية مستقلة.
- استُدعيت `web_search` فعلًا، وعادت نتيجة تحمل رابط توثيق Python الرسمي.

تطابقت ملفات Python المتعقبة والملفات الثابتة للواجهة والأقفال المختارة وعددها 492
بين الإصدار المنشور ورأس القياس. وسجلت مراقبة دورية استجابات سليمة من الدقيقة التاسعة
تقريبًا حتى الدقيقة الخامسة عشرة بعد النشر؛ لا يُدّعى اتصال المراقبة طوال الفترة.

## صلة الإغلاق بسجل المهام

طلب #144 المدموج في `5b5158da415deb07fd697e839d69878ce05af0d8` يحمل الأدلة
الحية السابقة المؤرخة في ٢٧ سبتمبر. كانت إحالتُه `Refs #23`، لذلك أعاد حارس
سجل المهام فتح #23 بعد إغلاقها يدويًا. يأتي طلب هذا الدليل بعبارة الإغلاق
المطلوبة، دون تعديل الحارس أو كتابة سجل إنجاز يدويًا. الأدلة السابقة تبقى
بتاريخها وحدودها؛ وهذا الملف لا يعيد نسبتها إلى إصدار اليوم.

## حدود الحكم

هذا قبول لطريقَي الأداة على عينات محددة، وليس قبولًا لجودة المحلّل (#44) أو البحث
المعمّق (#49)، ولا لقياس نموذج عام. الطلبات وجّهت النموذج إلى الأدوات صراحةً.
المجس لا يشهد بمقاومة هروب نواة Docker أو بمنع تزوير مدقق يعمل في المفسر نفسه.

الإنتاج ما زال يعتمد على الماك والنفق. لم تُنقل بيانات المالك إلى السحابة، ولم
تُختبر هنا ذاكرة إنتاج سحابية. احتُفظ بالأدلة الخام محليًا، وأُزيلت من الخلاصة
العامة معرّفات الوصول والجلسات والحاويات وعناوين التشغيل. يحمل المجس القديم
اسم عميله الأصلي ثابتًا؛ المشغّل الفعلي لهذه الإعادة هو `openai/codex`.
