## النمط الهجين — git والجهاز معًا

اختار المالك نمطَ تشغيلٍ هجينًا بثلاث أرجل، وgit هو الجسر الوحيد بينها:

١. **الرِّجل المحلية (أنت)** — جلسة Claude Code على الماك: يدُ المشروع على
   الجهاز (هرمس، العتاد، القياس)، **ويدُه على git أيضًا** عبر اعتمادات
   الماك نفسها (الاستنساخ نجح بها، فالدفع يعمل بها). فأنت وحدك تجمع
   الوصولَين، وهذا جوهر الهجين.
٢. **الرِّجل السحابية** — جلسةٌ في claude.ai/code معها وصول GitHub
   والفحص الدوري المجدول: تقرأ ما تدفعه، وتتابع CI،
   وتراقب طلبات السحب. لا وصول لها إلى الجهاز — عمدًا.
٣. **التحقق الآليّ** — ق٣٦–ق٣٨ يعدّان حاوية Linux ذاتية عابرة
   بعلامة `diwan-isolated` وتحقق Ed25519 عام دون أسرار. تسجيلها
   وترحيل البيانات وفصل التسجيل القديم بوابات تفعيل مستقلة؛ راجع
   الحالة الحالية أعلى الملف. القياس الحي على جهاز المالك يبقى محليًا.

التنسيق عبر git لا عبر نصوص: **كلُّ ما تدفعه إلى `main` تلتقطه الجلسة
السحابية في فحصها الدوري** وتبني عليه. فادفع النتائج، ولا تنتظر تنسيقًا آخر.

## وتحذيران يخصّان هذا الجهاز تحديدًا

- عليه **إرثٌ لم يُنظَّف**: مستودعات `lmai-*` و`kitaba-*` ومُشغِّلاتها
  وLaunchAgents وعمّال Cloudflare. **ليست شأنك** إلا إذا كلّفك المالك
  بالتنظيف صراحةً — وحينها: المُشغِّلات تُلغى أوّلًا والمستودعات آخرًا،
  و`the-room` لا يُمَسّ بقراره.
- هرمس يعمل هنا. **لا تعدّل إعداده** — المطلوب منه في هذه المرحلة حقيقتان
  يقرؤهما `tools/mac_probe.py` وسؤالُ واجهةٍ يجيب عنه المالك.
