# استخدام الملفات والتفضيلات والمسودات — م١٠ المحلية

هذه إضافة تجريبية للمحادثة: تقرأ ملفات نصية تختارها، وترسل نصها
وبصماتها وتفضيلاتك الصريحة مع الطلب إلى المزود المحلي. لا ينفذ
النموذج أدوات بنفسه. اقتراح الملف ومراجعته وتطبيقه عمليات صريحة
من واجهة المستخدم؛ لا تكفي عبارة داخل ملف أو جواب لتشغيلها.

هوية المزود وبصمته تُضبطان محليًا كما في `CHAT.md`. لا تُرسل هوية
المزود إلى مستودع المصدر. الجلسات الجديدة تحت `var/cli-workspace/`،
بعقد غرض مختلف عن `var/cli-chat/`؛ يرفض فتح العقد المخالف حتى عند
تساوي المسارات. التاريخ السابق في `var/chat/` لا يُنقل ولا يُستأنف
توليده تلقائيًا. استعمل معرفًا جديدًا، أو اقرأ جولة قديمة فقط:

```sh
.venv/bin/python tools/workspace.py --session notes --legacy-session replay --turn t1
```

## سؤال عن ملف اخترته

```sh
.venv/bin/python tools/workspace.py --session notes \
  --read-root "$DIWAN_SELECTED_DIRECTORY" \
  ask --turn t1 --message 'لخص الملاحظة وحدد ما يحتاج متابعة' --file note.txt
```

`DIWAN_SELECTED_DIRECTORY` مجلد تختاره أنت. كل `--file` مسار نسبي
تحته؛ أربعة ملفات كحد أقصى، وكل ملف UTF-8 بحد 65536 بايت. لا بحث
تلقائي في مجلداتك. تُرفض الروابط الرمزية والصلبة والملفات غير العادية
والعبور خارج الجذر والمسارات الداخلية المحمية. المحتوى يحفظ محارف
التنسيق العربية؛ NUL ومحارف التحكم التنفيذية مرفوضة. لا استخراج
PDF أو Word أو صور في هذه النسخة.

الحد المشترك لسياق الحوار 24000 محرف ويشمل التغليف والتاريخ؛ لذلك
قد يرفض ملفًا أصغر من حد البايتات إذا لم يسع السياق. الرفض قبل نداء
النموذج، ولا يقص النص أو يتجاهل ملفًا صامتًا. `--stdin` بديل عن
`--message` للنص متعدد الأسطر أو لتجنب ظهوره في معاملات العملية.

للجواب `inputs` يحدد بصمات الملفات ونسخة التفضيلات. هذا يثبت ما
أُرسل، لا صحة محتواه ولا حقوق إدخاله إلى مكتبة المصادر. الملفات
المختارة لا تتحول إلى `KnowledgeItem` أو مصدر موثق تلقائيًا.

## إعادة العرض دون المصدر

```sh
.venv/bin/python tools/workspace.py --session notes replay --turn t1
```

تعيد الجولة من بياناتها المحفوظة دون قراءة الملفات أو التفضيلات
الحالية، ودون إنشاء مزود. تعمل حتى لو حُذف مجلد المصدر. إعادة
`ask` بالهوية نفسها بعد تغيير المدخلات تُرفض؛ استعمل `replay`
للعرض القديم أو معرف جولة جديدًا لطلب يعتمد على البيانات الجديدة.
نصوص الملفات المرسلة محفوظة ضمن الجلسة محليًا وخارج git.

## التفضيلات: حفظ صريح ومراجعة وتعديل

```sh
.venv/bin/python tools/workspace.py preferences show
.venv/bin/python tools/workspace.py preferences set verbosity concise --revision 0
.venv/bin/python tools/workspace.py preferences delete verbosity --revision 1
```

استبدل رقم `--revision` بالنسخة التي أعادها `show`. إذا تغيرت النسخة
يُرفض التعديل المتأخر بدل فقد تحديث آخر. القيم المتاحة:

| المفتاح | القيم |
|---|---|
| `response_language` | `ar` أو `en` |
| `verbosity` | `concise` أو `balanced` أو `detailed` |
| `address_name` | اسم مخاطبة صريح حتى 80 محرفًا، دون محارف تحكم أو تنسيق خفية |

لا تعلم تلقائيًا من محادثة أو ملف، ولا محل للرموز أو كلمات المرور
في هذه الحقول. لكل طلب نسخة التفضيلات المستخدمة فيه؛ تغييرها
لاحقًا لا يعيد كتابة تاريخ الجلسة. الملفات خاصة بالحساب، وليست مشفرة.

## مسودة قابلة للمراجعة ثم كتابة جديدة

```sh
.venv/bin/python tools/workspace.py --session notes \
  propose --turn t1 --output summary.txt --request save-t1
.venv/bin/python tools/workspace.py review --proposal "$DIWAN_PROPOSAL_ID"
.venv/bin/python tools/workspace.py apply --proposal "$DIWAN_PROPOSAL_ID" \
  --sha256 "$DIWAN_REVIEWED_SHA256"
```

يُظهر `propose` النص والهدف والمعرف والبصمة، ويحفظ المسودة الخاصة
دون إنشاء ملف الهدف. ينشئ `apply` الملف فقط عند تطابق معرف المسودة
وبصمة محتواها، ويرفض استبدال أي ملف موجود. افتراضيًا تحت
`var/workspace-output/`؛ يمكن اختيار جذر مخرجات صريح بـ`--artifact-root`
مع استعماله نفسه في الاقتراح والمراجعة والتطبيق. المجلدات الداخلية
للأدوات محمية، والمجلدات الفرعية للهدف يجب أن توجد مسبقًا.

هذا فصل عمليات وربط بالمحتوى المعروض، وليس مصادقة هوية بشرية:
من يستدعي API يملك صلاحية استدعائه. لا يملك النموذج هذه الواجهة
في م١٠. لا يوجد shell أو تنفيذ شيفرة أو تعديل ملف قائم أو حذف.

عند إعادة تطبيق مسودة مكتملة يتحقق البرنامج من الملف وإيصال إنشائه
ويعيد الحالة دون كتابة. عند انقطاع غير محسوم يعلن `outcome_uncertain`
ولا يكتب فوق ملف أو يعيد الفعل عميانيًا. إذا تغير الملف المطبق يظهر
`applied_output_changed`. فساد الحالة يغلق المسار ولا يعيد تهيئتها.
الاقتراحات محدودة بـ256 لكل جذر؛ نقل السجل أو أرشفته خارج هذا الإصدار.

## حدود الفصل بين التعليمات والمحتوى

السياق JSON مغلق يميز `user_request` عن `untrusted_file` والتفضيلات.
لا يتحول محتوى الملف إلى حقل system أو صلاحية أداة، ولا تتولد كتابة
أو ذاكرة من جواب النموذج. هذه ضوابط آثار برمجية. يمكن أن يظل النموذج
متأثرًا بتعليمات مضللة داخل المحتوى؛ مقاومة الحقن دلاليًا غير مثبتة.
الأجوبة `unverified` والقبول البشري المستقل باقٍ وفق م٨.

دليل الآلية `acceptance_m10.py` مصطنع افتراضيًا، و`--live` يشغّل
ملف اختبار محليًا مرة واحدة. النتيجة والحدود في `M10-ACCEPTANCE.md`.
