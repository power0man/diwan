# دليل قبول م٠

**النصّ المتّفق عليه:** «طلب يمرّ ← جواب ← قيدٌ بالتكلفة الفعلية ← إيقافٌ عند السقف يُختبَر فعلًا.»

## كيف يُعاد إنتاجه

```sh
python3 acceptance.py        # ثمانية فحوص، وتخرج بغير صفر عند أيّ فشل
python3 -m pytest tests/ -q  # الاختبارات كاملة
```

## ما يُثبته كلُّ فحص

| # | الفحص | ما يمنعه |
|---|---|---|
| ١ | طلبٌ يمرّ ويعود بجواب | مسارٌ لا يكتمل |
| ٢ | القيد يحمل **التكلفة الفعلية المُسوّاة** لا المُقدَّرة — **والفرق بينهما مُحقَّق في الفحص** فلا يمرّ بتساويهما عرضًا | محاسبةٌ على التقدير، **وفحصًا عقيمًا يمرّ بلا أن يفرّق** |
| ٣ | سلسلة السجل سليمة | حارسٌ لا يحرس |
| ٤ | لا حجزَ معلّقًا بعد التسوية | تسرّبُ ميزانية |
| ٥ | **السقف يوقف قبل النداء** — والمزوّد لا يُنادى أصلًا | سقفٌ يُقرِّر بعد الصرف |
| ٦ | الرفض مُقيَّد في السجل | رفضٌ صامت |
| ٧ | المفتاح نفسه **يُعيد القيد ولا يُعيد الفعل** | أثرٌ مكرَّر بعد انقطاع |
| ٨ | التصنيف المحليّ لا يرى مزوّدًا بعيدًا | قيدُ خصوصيةٍ يفشل مفتوحًا |

## ما لا يُثبته

**لا يُثبت جودة نموذجٍ حيّ** — المزوّد هنا `echo` حتميّ محليّ، لا نموذج.
**ولا يُثبت صلاحية النظام لمهمّة حقيقية** — تلك م١، ودليلها أربعة شروط مجتمعة.
**ولا يُثبت خلوّ النواة من العيوب** — يُثبت **عدم تكرار العيوب المُثبَتة** (`tests/test_no_recurrence.py`).
**ولا يُثبت عزلَ بيئة التقييم** — فحصُ الاستيراد شرطٌ ضروري لا كافٍ (ق٩).

## ما وجده التدقيق العدائيّ على هذه الشيفرة

قبل أيّ دفعٍ، هُوجمت النواة بستة محاور و**كلُّ ادعاءٍ شُرط تشغيلُه**: ٣٨ وكيلًا، و**١٣ عيبًا مؤكَّدًا مُعادَ إنتاجه**، و١٨ ادعاءً أسقطه النقض، و٦ من ناقد الاكتمال.

| العيب | الضمان المكسور | حالته |
|---|---|---|
| `getattr(provider,"is_local",False)` يُقاس بالصدق المنطقي — فدالّةٌ غير مُستدعاة تُخرج حمولةً محليّة إلى السحابة | ٦ الخصوصية | **أُصلح** (ق١٠) + اختبارٌ بمَعلَمة على ٤ أشكال × تصنيفين |
| كلُّ مخرجٍ غير `ProviderError` يُسرّب الحجز ولا يُقيّد — **ومفتاح عدم التكرار يفشل مفتوحًا عند الانقطاع بالضبط** | ٤ و٥ | **أُصلح** (ق١١) + اختبارٌ على ٤ أنواع انقطاع |
| جوابُ المزوّد يُصدَّق، والمال يُخصم قبل أن يُبصَم القيد | ١ و٣ و٤ | **أُصلح** (ق١٢) |
| الرفضُ الماليّ يُسمّم مفتاح عدم التكرار أبدًا | ٥ | **أُصلح** (ق١٣) |
| المحاولاتُ في بنك القبول استشارية، والتجميعُ يكشف حالةً واحدة | ٧ | **أُصلح** (ق١٤) |
| نصٌّ ببديلٍ منفرد يجتاز الفحص ثم ينفجر عند البصم | ١ و٣ | **أُصلح** — `string_not_encodable` |
| قصُّ ذيل السجل وحقلٌ عُلويّ مدسوس لا يُكشفان | ٤ | **أُصلح** (ق١٥) — والحدّ الباقي مُعلَن |
| تصنيفٌ غير نصّيّ يكسر فحص العضوية بـ`TypeError` | ١ | **أُصلح** — `data_policy_type` |
| الفحص ٢ في دليل القبول عقيم (التقدير = المُسوّى في `echo`) | — | **أُصلح**: الفحص يشترط الفرق |
| اختبارُ الفصل بحثٌ عن نصٍّ في `.gitignore` | — | **أُصلح**: يُسأل `git check-ignore` |

**ولا يُدَّعى أنّ التدقيق استنفد العيوب.** يُدَّعى أنّ ما وُجد أُصلح، وأنّ لكلٍّ منه اختبارًا يمنع تكراره.
