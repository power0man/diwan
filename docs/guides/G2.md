# G2 — دليل ح٤ (نسخة مدقَّقة): تثبيت المراجِعين والمطوّرين وأدوات الأمان ولوحة المشروع على power0man/diwan

**الهدف:** بعد هذا الدليل يصير لديوان مراجِعٌ آليّ من عائلة Google باسم gemini-code-assist[bot] يحتسبه فحص family-review (وهو اليوم البوت الوحيد من عائلة google في registry/reviewers.json)، فينفتح الدمجُ الآليّ لطلبات Claude وCodex ويصير ق٤/١ (لا يراجع أحدٌ عمل عائلته) مفروضًا آليًّا لا بالأمانة؛ ويصير لمسار google مطوِّرٌ (Jules، المعرّف google/gemini-jules المسجَّل في registry/agents.json بتاريخ 2026-09-25) يُكلَّف بوسم jules؛ ويُعاد تشغيل مراجِع Codex (chatgpt-codex-connector[bot]) الذي توقّف لبلوغ حدّ الاستهلاك (تعليقه على PR #1 بتاريخ 2026-09-25)؛ ويُزال بوت Blocks (blocksorg[bot]) مجهول العائلة الذي كتب ١٢١ تعليقًا آليًّا بلا دور (آخرها اليوم 2026-09-26 على PR #121)؛ وتُفعَّل أدوات الأمان (CodeQL، وSecret scanning مع حماية الدفع، والإبلاغ الخاص، وتنبيهات Dependabot) بلا أيّ إيداعٍ آليّ يكسر قاعدة الذيل؛ وتُنشأ لوحة Projects v2 بالأعمدة والحقول والعرضين المحدَّدة في الخطة §٨. يُغلق هذا المسألةَ #56 (ح٤)، ويزيل شرطَ بدء ح١ (#53: جعل family-review إلزاميًّا في حماية main، وهو لا يمرّ اليوم لأن لا بوتَ مدرَجًا يراجع: فحصتُ مراجعات آخر ٢٠ طلبًا وكلّها github-actions[bot] فقط)، ويفتح تكليف Jules بمهام مسار google (ب٦، ب٧، ب١٠، ب١١) وإعادةَ تشغيل ك٣٠ (التنسيق آليًّا).

**الزمن:** ساعتان إلى ثلاث ساعات للمالك: Gemini ١٥ دقيقة، Jules ١٥ دقيقة، Codex ١٠ دقائق (زائد شراء الرصيد)، Blocks ٥ دقائق، الأمان ١٠ دقائق (وCodeQL يكمل تشغيله الأول وحده في ١٠–٣٠ دقيقة)، لوحة Projects ٤٥–٦٠ دقيقة (الحقول الأربعة وخياراتها الـ٢٧ هي أطول جزء). التحقق ١٥ دقيقة لـClaude على الماك (يلزم gh مثبَّت هناك). · **الكلفة:** إلزاميّ: $0 (Gemini Code Assist الطبقة المجانية، Jules Free، CodeQL وSecret scanning وPVR وDependabot alerts مجانية على المستودع العام، Projects مجاني). اختياري: رصيد Codex بالاستهلاك أو رفع خطة ChatGPT (~$20/شهر لـPlus) لإعادة مراجعة Codex؛ Google AI Pro ~$20/شهر إن ضاقت حصّة Jules. لا شراء لـCopilot ولا Devin ولا Cursor ولا Code Assist Standard (ق٦٢-٢). كل الأرقام evidence_level=training_knowledge بتاريخ 2026-09-26 ولم يتسنَّ تحقيقها بالبحث.

## قبل أن تبدأ

- حساب GitHub للمالك power0man بصلاحية المالك على المستودع العام power0man/diwan (تحقّقتُ عبر واجهة GitHub العامة اليوم: المستودع عام، الرخصة Apache-2.0، الفرع الافتراضي main، والمسائل #53 و#54 و#56 و#57 مفتوحة وموسومة owner-action).
- حساب Google شخصي @gmail.com للدخول إلى Jules وGemini Code Assist (الطبقة المجانية تكفي للبدء؛ evidence_level=training_knowledge لحدود الحصص).
- حساب ChatGPT الذي رُبط به Codex أصلًا. رسالة البوت على PR #1 تقول إنك «بلغت حدود الاستهلاك» وتطلب «إضافة رصيد وتفعيله للمراجعات» — أي أن الحساب مشترك أصلًا وبلغ حدَّه، لا أنه Free (evidence_level=primary_page من المستودع نفسه).
- متصفّحٌ على الماك مسجَّل الدخول إلى GitHub. الطرفية لخطوات التحقق فقط، وفيها gh (غير موجود في الحاوية السحابية؛ على الماك: brew install gh ثم gh auth login ثم gh auth refresh -s project,read:org).
- ما تحقّقتُ منه في المستودع قراءةً فقط: registry/reviewers.json يُدرج ثلاثة بوتات فقط (gemini-code-assist[bot]→google، chatgpt-codex-connector[bot]→openai، claude[bot]→anthropic) والحالتان المحتسَبتان APPROVED وCOMMENTED؛ .gemini/styleguide.md موجود بسبع قواعد؛ .gemini/config.yaml غير موجود؛ .github/dependabot.yml غير موجود (مقصود)؛ لا ملفّ CodeQL في .github/workflows؛ family-review.yml بصلاحيتَي contents: read وpull-requests: read؛ ووسوم jules وowner-decision وowner-action موجودة على GitHub بألوانها من labels.json.
- أمرٌ ذو صلة خارج نطاق ح٤ لكنه يشوّش عليه: المستودع فيه مراجِعُ Gemini الاستشاريّ (ك٥٤، gemini-review.yml) الذي ينشر باسم github-actions[bot] بمفتاح GEMINI_API_KEY يضعه المالك في Settings → Secrets and variables → Actions. مراجعاتُه لا تُحتسب في family-review ولا تغني عن تطبيق Gemini Code Assist. إن رأيت مراجعة «Gemini» على طلبٍ باسم github-actions[bot] فهي هذه لا التطبيق.
- لا تلصق أيّ مفتاحٍ أو سرّ في محادثةٍ مع أيّ ذكاء. كلّ سرٍّ يُكتب مرّةً واحدة في Settings → Secrets and variables → Actions أو في إعدادات الخدمة نفسها.

## الخطوات

### 1. المتصفّح على الماك: https://github.com/marketplace/gemini-code-assist (أو https://github.com/apps/gemini-code-assist)

افتح الصفحة واضغط الزرّ الأخضر Install it for free (أو Install/Add). اختر الحساب power0man، ثم Only select repositories وحدّد power0man/diwan (لا All repositories). راجع الأذونات المعروضة (قراءة المحتوى، وقراءة/كتابة طلبات الدمج ونحوها)، ثم اضغط Install.

**ما تتوقّع أن ترى:** صفحة GitHub تعرض التطبيق مثبَّتًا على مستودعٍ واحد، ويظهر Gemini Code Assist في https://github.com/settings/installations.

> evidence_level=training_knowledge لعنوان الصفحة واسم الزرّ ونصّ الأذونات (تعذّر التحقق: ميزانية البحث مستنفَدة ٢٠٠/٢٠٠، وجلب developers.google.com محجوب EGRESS_BLOCKED). المقصود ثابت: تثبيتٌ على مستودعٍ واحد لا على كل المستودعات.

### 2. المتصفّح: قد يعيد التثبيت توجيهك إلى صفحة Google لإكمال الربط

إن طُلب منك تسجيل الدخول بحساب Google فسجّل بحسابك الشخصي @gmail.com ووافق على ربط حساب GitHub بحساب Google. لا يلزم شراء Code Assist Standard؛ الطبقة المجانية هي المطلوبة في الخطة §٣.

**ما تتوقّع أن ترى:** صفحة تأكيد من Google أن Gemini Code Assist مرتبط بحساب GitHub power0man.

> العدد الدقيق لمراجعات اليوم في الطبقة المجانية غير متحقَّق (evidence_level=training_knowledge)؛ ستعرفه من أول رسالة تجاوزٍ إن ظهرت.

### 3. لا شيء يُغيَّر في المستودع

لا تنشئ أيّ ملف إعداد. الملف .gemini/styleguide.md موجود في جذر المستودع ويقرؤه التطبيق تلقائيًّا، وهو يأمر المراجِع ألا يراجع طلبات عائلة Google (Jules) وأن يفصل العيب الحاجب عن الاقتراح. ملف .gemini/config.yaml اختياري وغير موجود، ولا حاجة إليه الآن.

**ما تتوقّع أن ترى:** لا تغيير.

> تحقّقتُ من المستودع أن الملف موجود (٧ قواعد) وأن config.yaml غير موجود. حدٌّ معلَن: الدليل لا يمنع التطبيق تقنيًّا من مراجعة طلبات Jules، لكن family-review يتجاهل مراجعة العائلة نفسها بحكم الشيفرة (tests/test_family_review.py) فلا ضرر.

### 4. المتصفّح: أيّ طلب دمجٍ مفتوح على https://github.com/power0man/diwan/pulls، أو انتظر أوّل طلبٍ يفتحه Claude

افتح طلب الدمج وانتظر دقيقةً إلى ثلاث. يجب أن تظهر مراجعةٌ باسم gemini-code-assist[bot] (ملخّص ثم ملاحظات). إن لم تظهر، اكتب تعليقًا نصّه /gemini review ثم Comment.

**ما تتوقّع أن ترى:** في تبويب Conversation مراجعةٌ باسم gemini-code-assist[bot] بحالة Comment أو Approve. هذا الاسم بالضبط هو المدرَج في registry/reviewers.json تحت عائلة google. لا يحتسب family-review مراجعة github-actions[bot] (ومنها مراجعة Gemini الاستشارية ك٥٤ التي قد تراها على الطلب نفسه بعنوان Gemini) ولا أيّ بوتٍ غير مدرَج.

> تحقّقتُ اليوم عبر واجهة GitHub العامة: مراجعات آخر ٢٠ طلبًا (#92–#121) كلّها github-actions[bot] بحالة COMMENTED (٢٧ مراجعة) ولا واحدة من gemini-code-assist[bot]؛ فظهوره هو الدليل على نجاح الخطوات ١–٣. أمر /gemini review من المعرفة السابقة (evidence_level=training_knowledge).

## احذر

- تعذّر التحقق من صياغات الواجهات في هذه الجلسة: ميزانية WebSearch مستنفَدة (٢٠٠/٢٠٠)، وجلب docs.github.com وdevelopers.google.com وjules.google وdevelopers.openai.com محجوب (EGRESS_BLOCKED، جُرّب مرّةً لكلٍّ). فكل أسماء الأزرار والقوائم evidence_level=training_knowledge وقد تختلف قليلًا؛ ما تحقّقتُ منه فعلًا هو حالة المستودع وملفّاته وواجهة GitHub API العامة (بتاريخ 2026-09-26).
- تفعيل Gemini Code Assist يجعل family-review قابلًا للمرور، لكن الفحص يشهد أن عائلةً أخرى راجعت الرأس الحالي فقط، لا أن ملاحظاتها عولجت (حدّ معلَن في registry/reviewers.json). وإن ختم مراجِعٌ محتسَب مراجعةً بحالة Request changes يسقط الفحص حتى تُعدَّل أو تُلغى (tests/test_family_review.py).
- طلبات Jules (عائلة google) لا تُحتسب لها مراجعة Gemini؛ يحتاج كل طلبٍ من Jules مراجعةً من claude[bot] أو Codex. ولم يُثبَّت claude[bot] بعد، فحتى يُثبَّت يبقى Codex (بعد شحنه) المراجعَ الوحيد المحتسَب لطلبات Jules.

- Codex: المراجعة تستهلك رصيدًا؛ إن نفد تعود رسالة usage limits ويتوقّف بصمت (كما حدث في PR #1). راقب https://chatgpt.com/codex/cloud/settings/usage. حدود الخطط غير متحقَّقة.
- CodeQL default setup يعمل بنفسه على Actions ويطلق تنبيهات في تبويب Security؛ قد يُكثر من التنبيهات منخفضة الخطورة في webui/JavaScript. لا يُودِع شيئًا. لا تجعله فحصًا إلزاميًّا في ح١ إلا بقرارٍ لاحق.
- حماية الدفع (Push protection) قد ترفض دفعةً فيها نصٌّ يشبه مفتاحًا حتى لو كان مثالًا في وثيقة؛ الحلّ تعديل الإيداع لا تجاوز الحماية.
- الأتمتة Auto-add to project قد تكون محدودة على لوحات المستخدم في الخطة المجانية؛ البديل يدويّ أو سيرٌ يحتاج رمزًا دقيق الصلاحية يوضع في Secrets وحدها.
- إزالة Blocks تحذف صلاحياته فقط؛ تعليقاته الـ١٢١ تبقى في التاريخ ولا تُحذف (ولا داعي لحذفها). وما دام البوت نشطًا (علّق اليوم) فكل طلبٍ جديد سيحمل تعليقه حتى تُتمّ الخطوة ١١.
- الحقول الأربعة في اللوحة تكرّر الوسوم؛ إن اختلفت قيمة الحقل عن الوسم فالوسم هو الحقيقة (labels.json يُزامَن آليًّا) واللوحة عرضٌ للمالك فقط.
