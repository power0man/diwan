## الخطوات

### 1. الماك → تطبيق Terminal

افتح الطرفية ونفّذ:
cd ~/diwan-work/diwan && git pull origin main && uv sync --extra dev && export DATE=$(date +%Y%m%d) && echo $DATE
ثم تأكّد من الخدمات:
docker info >/dev/null && echo docker-ok && ollama list | grep qwen3.5:9b && echo engine-ok

**ما تتوقّع أن ترى:** سطر تاريخ مثل 20260927، ثم docker-ok وengine-ok. وكل أمرٍ في هذا الدفتر يُنفَّذ من هذا المجلّد؛ وحيث تكتب الوثائق python3 نكتب هنا uv run python (بيئة القفل نفسها)

> --extra dev يركّب pytest==9.1.1 الذي تحتاجه الخطوتان 18 و26؛ uv sync وحده لا يركّبه (pyproject.toml: [project.optional-dependencies] dev). ومتغيّر DATE يعيش في نافذة الطرفية هذه فقط؛ إن فتحت نافذة جديدة أعد سطر export

### 2. الماك → Terminal في ~/diwan-work/diwan

فحص الدخان قبل أي قياس:
uv run python tools/launch_check.py --engine qwen3.5:9b; echo exit=$?

**ما تتوقّع أن ترى:** الخطوات الستّ (runtime, morphology, engine, agent_turn, policies, ui) ok وexit=0. إن ظهر exit=3 مع policies: corpus_missing أو index_missing فهذا متوقَّع قبل الخطوة 11 ولا يمنع الخطوات 3–10

> exit=1 عطب: أوقف الدفتر وأعطِ الجلسة السحابية السطر الأحمر. (رموز الخروج 0/3/1 متحقَّقة من tools/launch_check.py --help)

### 3. الماك → Terminal

بناء صورة المحلّل وإيصالها مرّةً (docs/ANALYST.md §٣-١). تخطَّ هذه الخطوة إن كان الملف موجودًا (ls -l ~/.config/diwan/analysis-receipt.json):
mkdir -p ~/.config/diwan && uv run python analysis/prepare.py --receipt ~/.config/diwan/analysis-receipt.json
وإن كان بناء Docker يمرّ بوكيلٍ يعيد توقيع TLS أضف --pip-ca <مسار شهادة الوكيل>

**ما تتوقّع أن ترى:** بناءٌ ناجح وملف إيصال بصلاحيات 0600 في ~/.config/diwan/analysis-receipt.json. الزمن ٥–١٥ دقيقة (تنزيل pandas/matplotlib داخل الصورة من analysis/requirements.lock)

> الإيصال القائم لا يُكتب فوقه إلا بـ--replace؛ ولا تستعمل --replace إلا إن تغيّر analysis/requirements.lock. (الخيارات --receipt و--replace و--docker و--pip-ca متحقَّقة من --help)

### 4. الماك → Terminal

تحقّق من إيصال التشغيل (runtime receipt) الذي تُشغَّل به أوامر النجاح في حاوية:
ls -l "$DIWAN_STATE/runtime.json"
(إن لم يكن DIWAN_STATE معرَّفًا في نافذتك فابحث عنه في ملفّ الصَّدَفة: grep -n DIWAN_STATE ~/.zshrc ~/.zprofile ~/.bash_profile 2>/dev/null)
وسجّل المسار في متغيّر:
export RUNTIME_RECEIPT="$DIWAN_STATE/runtime.json"
إن لم يكن موجودًا فابنِه مرّةً بأمر docs/CI-SIGNING-IMPLEMENTATION.md §د من نسخة الأدوات الموثوقة خارج نسخة العمل (DIWAN_PYTHON هو بايثون البيئة المعزولة $DIWAN_STATE/owner-venv/bin/python من §أ):
"$DIWAN_PYTHON" "$DIWAN_TRUSTED_SOURCE/ci/prepare_runtime.py" --python-image 'python:3.14-slim-bookworm@sha256:<digest راجعته>' --node-image 'node:24-bookworm-slim@sha256:<digest راجعته>' --lock "$DIWAN_REPO/requirements-ci.lock" --trust-json "$DIWAN_STATE/trust.json" --receipt "$DIWAN_STATE/runtime.json" --runner-receipt "$DIWAN_STATE/runner.json"

**ما تتوقّع أن ترى:** ملف JSON فيه image_id وlock_sha256 وpython_version (كما في config.execution_receipt في docs/probe/j8-analyst-20260926.json). البناء ١٠–٢٠ دقيقة إن لزم

> الخيارات كلها متحقَّقة من ci/prepare_runtime.py --help؛ --platform افتراضه linux/arm64 فلا يلزم على الماك، و--runner-receipt اختياري (يبني صورة المشغّل الزائل أيضًا كما في الوثيقة). المسار الفعلي على جهازك غير مسجَّل في المستودع العام؛ إن لم تجد المتغيّرات اسأل جلسة الماك

### 5. الماك → Terminal

إعادة قياس بنك المحلّل ك٥٠ على المُشغِّل الإصدار ٧ (docs/ANALYST.md §٣-٣ و§٤):
uv run python tools/evaluate_agentic.py --suite evaluation/suites/analyst_v1.json --model qwen3.5:9b --execution-receipt "$RUNTIME_RECEIPT" --analysis-receipt ~/.config/diwan/analysis-receipt.json --out docs/probe/j8-analyst-$DATE.json

**ما تتوقّع أن ترى:** ملف docs/probe/j8-analyst-<DATE>.json فيه config.runner_version = 7 (القياس السابق كان 6) وsummary.errors = 0 (في القياس السابق كانت ٧ مهامّ execution_backend_unavailable) وthresholds.meets_thresholds بحكمه. الزمن نحو ٣٠ دقيقة (القياس السابق ١٦٨٩ ثانية لأربعين مهمّة). يغذّي قرار ج٨: العتبة ٠٫٧٠ ولا فئة دون ٠٫٥٠ (docs/ANALYST-BANK.md)

> الأداة ترفض الكتابة فوق ملفٍّ قائم؛ لا تحذف تقريرًا قديمًا بل غيّر التاريخ أو أضف لاحقة -b. (RUNNER_VERSION = 7 متحقَّق من evaluation/agentic_runner.py)

### 6. الماك → Terminal

قياس بنك المبرمج ك٤٤ بعتبات ك٥١ في وضع المبرمج (docs/CODER.md §٤):
uv run python tools/evaluate_agentic.py --suite evaluation/suites/agentic_v2.json --mode coder --model qwen3.5:9b --execution-receipt "$RUNTIME_RECEIPT" --out docs/probe/j9-coder-$DATE.json
وبعده، اختياريًّا للمقارنة بالحلقة العامة (docs/AGENTIC-BANK.md §٥):
uv run python tools/evaluate_agentic.py --suite evaluation/suites/agentic_v2.json --model qwen3.5:9b --execution-receipt "$RUNTIME_RECEIPT" --out docs/probe/k44-agentic-v2-$DATE.json

**ما تتوقّع أن ترى:** docs/probe/j9-coder-<DATE>.json فيه config.system_sha256 وthresholds بحكمه (العتبات في evaluation/suites/agentic_v2.meta.json: إجمالي ≥٠٫٦٠، bug_fix ≥٠٫٥٠، feature ≥٠٫٥٠، refactor ≥٠٫٤٠، explain ≥٠٫٦٠، workspace_files ≥٠٫٦٠، ومخالفات وعبث = صفر) وconfig.success_executor = docker. الزمن ٢٥–٤٥ دقيقة لكل تشغيلة (٣٠ مهمّة). يغذّي قرار ج٩: هل يُعلَن وضع المبرمج مستوفيًا، وأي فئة تحتاج عملًا

> هذا التقرير نفسه هو الدليل الحيّ على أن أوامر النموذج (run_tests) تجري في DockerExecutionBackend على الماك (ج٥ الشطر الثاني). --mode {agent,coder} متحقَّق من --help

### 7. الماك → Terminal

إعادة قياس بنك البحث المعمّق ك٥٣ بعد سدّ ثغرة المدقّق في ك٤٦ (docs/RESEARCH-BANK.md §٦):
uv run python tools/evaluate_research.py --model qwen3.5:9b --out docs/probe/k53-research-$DATE.json

**ما تتوقّع أن ترى:** ملف فيه summary.pass_rate وcitation_valid_rate وfabricated_sources وerrors (السابق في docs/probe/k53-research-20260926.json: ٠٫١٠٣ و٠٫٣٤٥ و٠ و١). الزمن ٢٠–٦٠ دقيقة (٣٠ سؤالًا، الافتراضيان --deadline-s 180 و--max-steps 8). يغذّي: هل تُفتح مهمّة تحسين تعليمات البحث (القفزة الثانية) أم يُقبل الرقم ويُنشر

> بلا شبكة إلا Ollama المحلي؛ المحرّك FixtureSearch (BM25 على متن البنك) لا SearXNG — متحقَّق من evaluation/research_runner.py

### 8. الماك → Terminal (ليلًا، بلا واجهة مفتوحة)

**ما تتوقّع أن ترى:** ملف فيه judgment.decision (keep/remove/inconclusive/underpowered) وjudgment.overall.ci95 وjudgment.overall.pairs ≥ ٤٦١. الزمن تقديرًا ٣–٦ ساعات (٥٨٢ حالة × ذراعان على الطريق الوكيل؛ الطريق النصّي قاس ٣٧٦ حالة في ٣١ دقيقة). يغذّي قرار ك٤٦: إبقاء إعلان أدوات المنتج في الجولة العامة أو حذفه

> --no-sandbox لأن الماك بلا حاوية فحص python_sandbox؛ بدونه تُسجَّل تلك الحالات خطأً (docs/ABLATION.md §٣). البنك الافتراضي evaluation/banks/kimi_v1/open — فإن نفّذت الخطوة 20 قبل هذه الخطوة تعطّل الاستئصال لغياب المجلّد: نفّذ الاستئصالات الثلاثة قبل الخطوة 20 أو بعد الخطوة 23. إن رفض فاحص أمان الجلسة إطلاق الحلقة فشغّله أنت في الطرفية لا من داخل الجلسة
