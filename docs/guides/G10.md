# G10 — Obsidian غرفةَ تحكّمك: خزنة الخطة والمهامّ وصندوق الوارد

**الهدف:** أن تفتح Obsidian فترى الخطة المعتمدة ولوحة المراحل ومهامّ كل ذكاء وخطواتك بمربّعات اختيار، وأن تكتب طلباتك في صندوق وارد يقرؤه Claude على الماك. الخزنة ملفات Markdown عادية على جهازك، خارج المستودع، ولا تُرفع إلى أي مكان.

**الزمن:** ١٠ دقائق لك، بعد أن يركّبها Claude · **الكلفة:** $0 (Obsidian مجاني للاستعمال الشخصي والعمل؛ Sync المدفوع غير لازم — يُتحقَّق من الشروط الحالية)

## قبل أن تبدأ

- جلسة Claude على الماك مفكوكة الحجب (G4 الخطوات ١٠–١٦)
- دمج طلب Obsidian في main (فيه الأداة `tools/obsidian_vault.py`)

## الخطوات

### 1. جلسة Claude على الماك

اطلب: «ركّب Obsidian وابنِ الخزنة». يشغّل Claude: `brew install --cask obsidian` ثم `cd ~/diwan && git pull && uv run python tools/obsidian_vault.py build --vault ~/Diwan-Vault`.

**ما تتوقّع أن ترى:** سطر JSON فيه عدد الملفات المكتوبة، ومجلّد `~/Diwan-Vault` فيه `Diwan/` و`Inbox/`.

> إن لم يكن Homebrew مركّبًا فنزّل Obsidian من https://obsidian.md/download واسحبه إلى Applications.

### 2. الماك: تطبيق Obsidian

افتح Obsidian ← Open folder as vault ← اختر المجلّد `Diwan-Vault` في مجلّدك الشخصي ← Open. وإن سُئلت عن الإضافات المجتمعية (Community plugins) فاتركها معطّلة.

**ما تتوقّع أن ترى:** في الشريط الجانبي مجلّدا `Diwan` و`Inbox`.

### 3. Obsidian: Diwan/ابدأ هنا

افتح «ابدأ هنا»، ثم «لوحة المراحل» و«خطواتي». اضغط على أي رابط [[…]] لتنتقل إلى المهمّة أو الدليل.

**ما تتوقّع أن ترى:** كل مهمّة ملاحظةٌ فيها منفّذها ومرحلتها ومُخرجها ودليل قبولها وما تعتمد عليه.

### 4. Obsidian: Diwan/خطواتي

علّم الخطوة حين تنتهي منها بالضغط على مربّعها. هذه الملاحظة لك: لا تكتب الأداة فوقها بعد إنشائها.

**ما تتوقّع أن ترى:** علامة ✓ تبقى بعد كل إعادة بناء.

### 5. Obsidian: مجلّد Inbox

لكل طلب ملاحظة جديدة (Ctrl/Cmd+N داخل Inbox)، سطرها الأول عنوان الطلب. مثال: «شغّل استئصال tool_announcement الليلة».

**ما تتوقّع أن ترى:** في بداية جلسته يشغّل Claude على الماك `tools/obsidian_vault.py list-inbox`، ويحوّل ما يلزم إلى مسألة GitHub بموافقتك، ثم ينقل الملاحظة إلى `Inbox/منجز`.

### 6. جلسة Claude على الماك

بعد كل دمج في main يعيد Claude البناء بالأمر نفسه. وللتحقّق في أي وقت: `uv run python tools/obsidian_vault.py check --vault ~/Diwan-Vault`.

**ما تتوقّع أن ترى:** خروج 0 حين تطابق المرآةُ المستودع.

### 7. اختياري: Nitro (ويندوز)

للقراءة على Nitro: `winget install -e --id Obsidian.Obsidian` في PowerShell. والخزنة نفسها تبقى على الماك؛ لا تنسخها إلى Nitro إلا بقرارك.

**ما تتوقّع أن ترى:** Obsidian مركّب على ويندوز.

## كيف تتأكّد أنه نجح

- `check` يخرج 0 على الماك
- لا يظهر `Diwan-Vault` في `git status` داخل ~/diwan
- ملاحظة في Inbox تتحوّل إلى مسألة ثم تنتقل إلى منجز

## احذر

- لا تكتب في Inbox مفتاحًا أو توكنًا أو نصًّا من لوائحك غير المنشورة: ما يتحوّل إلى مسألة GitHub يصير عامًّا.
- ما تعدّله داخل Diwan/ (غير خطواتي) لا تكتب الأداة فوقه، فيتقادم؛ اكتب ملاحظاتك الخاصة خارج Diwan/.
- وضع الخزنة داخل Google Drive خيارك، والأداة لا تمنعه. المرآة عامة أصلًا، أما Inbox فطلباتك.

## خطوات لم يُتحقَّق من صياغتها في الواجهة

- اسم حزمة winget `Obsidian.Obsidian` وحزمة Homebrew `obsidian` من معرفة التدريب؛ يتحقّق منهما Claude عند التركيب.
- شروط الترخيص الحالية لـObsidian (مجاني للعمل منذ ٢٠٢٥) لم تُقرأ من صفحة أولية في هذه الجلسة.
