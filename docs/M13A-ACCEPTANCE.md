# م١٣-أ — استعادة مساحة العمل وفحص حدود النشر

**٢١ سبتمبر ٢٠٢٦، ق٣٤.** نطاق تقني محلي من م١٣؛ لا إغلاق لمرحلة
التوسع والنشر أو بوابات الجودة. لا عقد تخصصية جديدة بلا منفعة مقيسة.

## المخرج

`workspace_tools/backup.py` و`tools/workspace_backup.py` لنسخ مساحة
عمل مغلقة وفحص نسختها واستعادتها إلى وجهة جديدة. العقد في `BACKUP.md`.
تُتحقق حالة المحادثات والتفضيلات والملفات على نسخة مؤقتة؛ المصدر
لا يُهيأ ولا تُحسم جولاته المعلقة. تُحفظ بايتاته وأوقاته وهوياته.

الاستعادة تنشئ الملفات وتعيد ربط إيصالات `applied` المتحققة فقط،
وتوثق ذلك محليًا. لا إنشاء مزود أو تكرار `apply` أو اعتماد مسودة.
علامة نية مثبتة قبل إنشاء الوجهة تغطي الانقطاع قبل أول ملف؛ تفحصها
الواجهة قبل إنشاء الجذر وقبل أخذ قفله. يبقى الفشل مغلقًا عبر اختلاف
حالة الأحرف وNFC/NFD لأسماء المجلدات على Mac.

أضيف `publish_projection.plan` و`--check` لفحص المصادر والمواد
وأسماء النواتج والحقوق دون تغيير إسقاط النشر. أصبح `build` يجري
هذا الفحص كاملًا قبل حذف المخرجات أو إلحاق رفض في البيان، ويتحقق
من البيان وإمكان توقيعه قبل التغيير. قراءة السجلات تستخدم
`create=False` فلا تنشئ الغائب أو تغير mtime للموجود؛ يشمل ذلك
قارئ سجل المحادثة بعد أن كان يلمس mtime في المراحل السابقة.

تجربة القبول تنشئ مشروعين وثلاث جولات بمزود مصطنع (نص، PNG، WAV)،
وتفضيلًا ومرفقًا وملفًا مطبقًا ومقترحًا غير مطبق. تستعيدها إلى جذر
جديد وتسترجع التاريخ والمدخلات بمصنع مزود يفشل إذا استُخدم. تعيد
عرض إيصال الملف دون تغيير بايتاته أو mtime، وتتحقق من بقاء المقترح
غير منفذ، ومن رفض البصمة الخاطئة والوجهة القائمة والفساد والتعليق.

اختبار النشر يستعمل مصادر مصطنعة فقط: مسموح، داخلي، وسم توزيع
مخالف للسجل، ومصدر مجهول، ثم سحب إذن المصدر بقيد جديد. لا تمر مادة
محجوبة، ويزول النص المسحوب من **الإسقاط المصطنع** عند إعادة بناء
ناجحة. القياسات في `probe/m13-restore-20260921.json`.

## التدقيق والتفنيد

### فحص الأصل بعد المزامنة

نجح CI للالتزام `fd7aa81` ثم زومنت نسخة المالك إليه وتحققت مراسيها
الثمانية مع فرض التوقيع. شُغلت `plan` من شيفرة المستودع الأصلي على
مصادره الفعلية: صفر مادة قابلة للنشر، و33341 مادة محجوبة بوسمها،
دون مخازن غائبة. ظلت بايتات 268 ملفًا وmtime وهوياتها ثابتة قبل
الفحص وبعده. لم يُطبق نشر أو تتغير الحقوق. الدليل المجمل في
`probe/m13-publication-check-20260921.json`؛ هذه قراءة للحالة الفعلية
وليست إذنًا حقوقيًا أو اختبار كتابة نشر حقيقي.

### المراجعات المستقلة

راجع A التصميم والتنفيذ، وراجع B وC الاستعادة والنشر والقبول؛
وأضيف D مستقلاً لفحص العقود وأسماء الملفات. لكل عيب مثبت أدناه
مفندان مستقلان واختبار يعيد الحالة، ثم فحص للإصلاح.

| العيب | السبب والأثر | الإغلاق |
|---|---|---|
| C1 | حذف الإسقاط السابق قبل اكتمال فحص مخزن تالٍ أو إلحاق رفض قبل فشل لاحق | خطة مكتملة قبل أي تغيير؛ المصدر الفاسد أو غياب مفتاح البيان يبقي المخرجات السابقة |
| B2 | المخزن الداخلي فقط يتجاوز فحص سجل الأصول لأن البوابة تُستدعى للمرشح القابل للتوزيع فقط | فحص سجل الأصول الصارم غير مشروط بعدد الصفحات المرشحة |
| P1 | إعداد جلسة media صالح للحوار العام لكنه غير مقبول في خدمة الوسائط يمر النسخ | تحقق MediaAssistant على النسخة قبل قبولها؛ مثال max_output=401 مرفوض |
| C2 | فشل بعد mkdir وقبل العلامة يجعل وجهة فارغة قابلة لفتحها كمساحة جديدة | نية أبوية متينة قبل mkdir، وحظر الواجهة قبل أي تهيئة؛ تبقى النية عند الفشل |
| B3 | اسم بديل بحالة أحرف أو Unicode مختلفة يشير إلى نفس المجلد لكنه يحسب نية أخرى | NFC+casefold قبل حساب اسم النية؛ اختبارات بأسماء بديلة فعلية على Mac |
| D1 | معرف وثيقة فيه slash أو محارف ممنوعة أو طول زائد يفشل بعد حذف القديم | التحقق من اسم المخرج النهائي وطوله في الخطة قبل التغيير |
| D2 | أسماء مختلفة تتطابق على القرص فتستبدل إحداها الأخرى مع تقرير عدد خاطئ | رفض تصادم NFC+casefold بين أسماء النواتج قبل الكتابة |
| D3 | سلسلة صفحة ومرساة صحيحتان لا تثبتان صحة item_digest الداخلي | CorpusFile.verify(strict=True) قبل تمرير الصفحات، حتى للمواد الداخلية |

نجاح البصمة المقدمة للأرشيف لا يعفيه من فحص البنية والسجلات
والإيصالات؛ الأرشيف المشوه ذو بصمة خارجية مطابقة ما زال مرفوضًا.

## الحدود والبوابات المفتوحة

- الاستعادة هنا دليل آلي ببيانات مصطنعة، وليست تجربة بشرية لحسين
  أو اختبار نسخ جهاز كامل أو قرص تالف. النسخ غير مشفر ومحدود الحجم.
- `plan` يحافظ على المدخلات والإسقاط. تصحيح `build` يغطي فشل
  التحقق قبل الكتابة؛ **الكتابة متعددة الملفات ليست معاملة ذرية**
  أمام عطل وسيط أو انقطاع أو بنّائين متزامنين. النشر الفعلي يبقى
  مؤجلًا؛ يلزمه التزام جيل كامل وتعافٍ قبل إتاحة خارجية.
- م٨-ب وبنوك الوسائط المستقلة وحكم المراجع واستخدام المالك اليومي
  باقية. لا يعوّضها نجاح 1393 اختبارًا أو جوابا الصورة والصوت.
- بند حقوق المتون الكاملة في المستودع الخاص ما زال بيد المالك،
  ولا تعديل لوسوم حقوق حقيقية أو نشر حقيقي في هذه الدفعة.
- م١٣-ب للتوسع والنشر لم تُنجز. اختيار تخصص جديد يتطلب مهمة ومنفعة
  مقيسة، ومصدر قدرة جديد أو إنفاق أو خدمة دائمة يحتاج قراره المنفصل.
  `release_ready=false` ثابتة حتى إغلاق البوابات ذات الصلة.
