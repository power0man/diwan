11. programming — ag11_python_stable_unique

حالة التنفيذ: complete؛ حالة حرجة: لا

المهمة وسياقها

المستخدم: اكتب دالة Python اسمها unique_even(values). المدخل قائمة أعداد صحيحة، وقد تشمل صفرًا وأعدادًا سالبة، ولا تشمل قيم bool. تعيد الدالة الأعداد الزوجية دون تكرار وبترتيب أول ظهور لها، وتعيد قائمة فارغة للمدخل الفارغ. لا تعدل قائمة المدخل، ولا تقرأ ملفات أو شبكة. أخرج الدالة وحدها، ولا تدع أنك نفذت الشيفرة أو اختبرتها.

جواب النموذج

def unique_even(values):
    seen = set()
    result = []
    for num in values:
        if num % 2 == 0 and num not in seen:
            seen.add(num)
            result.append(num)
    return result
المرجع ومعايير الحكم
حل مقبول يستعمل قائمة نتيجة ومجموعة seen، ويمر على values بالترتيب، فيضيف كل قيمة تحقق value % 2 == 0 ولم ترد في seen. للمثال [4, 2, 4, 3, 0, -2, 2] يجب أن يعيد [4, 2, 0, -2] وأن يبقي المدخل دون تغيير. لا تنفذ الشيفرة الناتجة ضمن هذه الحزمة؛ يراجع الإنسان منطقها.
  • يعرّف unique_even(values) ويعيد قائمة، مع دعم الفراغ والصفر والأعداد الزوجية السالبة.
  • يحافظ على ترتيب أول ظهور ويحذف التكرار؛ لا يعتمد على ترتيب مجموعة ولا يفرز القيم.
  • لا يعدل المدخل أو يستعمل ملفات أو شبكة، ويخرج الدالة وحدها دون ادعاء تشغيل أو اختبار.
  • يراجع الإنسان المسار المنطقي للمثال والحدود؛ وجود اسم الدالة وحده لا يثبت صحة التنفيذ.
