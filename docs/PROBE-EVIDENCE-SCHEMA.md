# مخطط أدلة القياس العامة

يوفّر `tools/probe_evidence.py` حارسًا قابلًا للنشر لملفات JSON التي تُمرّر إليه
صراحةً. يفرض الدليل الحالي حقول `agent` و`date` و`measurement_limits`، ويفرض على
الدليل التاريخي إحالةً آمنة إلى خليفةٍ موجود ضمن المجموعة التي يزوّدها المستدعي.

يرفض الحارس بيانات الوصول والبيانات التشغيلية المحلية أو البعيدة، ويعيد رموز أخطاء
مجمعة فقط. لا يطبع اسم ملف أو مساره أو اسم حقل حساس أو القيمة التي سببت الرفض.
وتثبت الاختبارات هذا السلوك ببيانات مصطنعة لا تمثل تشغيلًا أو حسابًا حقيقيًا.

## حد النطاق

لا يكتشف الحارس ملفات المستودع تلقائيًا ولا ينشئ فهرسًا عامًا لها. جرد الأدلة الكامل
وتنقيح الملفات التشغيلية التاريخية محجوبان في بيئة النشر الحالية، ولذلك لم يُنشرا
ولا يُعد هذا النطاق إكمالًا للقضية #188 أو دليلًا على قبول جميع الأدلة السابقة.

مثال على تحققٍ آمن من ملف مصطنع:

```bash
python tools/probe_evidence.py /tmp/synthetic-probe.json
```
