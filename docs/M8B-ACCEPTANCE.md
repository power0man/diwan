# م٨-ب — دليل آلية القبول والمراجعة

**٢١ سبتمبر ٢٠٢٦. الحالة: الآلية مبنية ومختبرة؛ المرحلة لم تُغلق.**
المراجع: ق٢٨، و`M8B-PROTOCOL.md`، وخارطة ق٢٧.

## نطاق المنجز

`AcceptanceStore` يحفظ المحاولات والدرجات والتجميع والكشف عبر إعادة
التشغيل، ببيان ثابت وقفل وحالة ذرية. الفحوص ترفض تغير البنك أو المرشح
أو سياسة المحاولات، وترفض محاولة أو تجميعًا جديدًا عندما تصبح
المجموعة أصغر من خمسة. يبقى التجميع التاريخي ثابتًا والكشف الفردي
المعلن ممكنًا. لا تسقط المحاولة المفتوحة عند إعادة إنشاء الكائن.

مسار `human_review` ينشئ حزمة HTML للأجوبة الفعلية، ويستقبل ملف حكم
يرتبط ببصمات التقرير والبنك والإعداد والجواب. جميع اختبارات الأحكام
مصطنعة وموسومة؛ لم يكتب وكيل حكمًا بشريًا على أجوبة النموذج الحية.

| اختبارات المشروع بعد الإضافة | **466/466** |

| تحضير حزمة من القياس الحقيقي السابق | **15 حالة**، دون نداء نموذج جديد أو قرار بشري مصطنع |

نُفّذ JavaScript للتصدير في بيئة Node بواجهة DOM مصطنعة، ثم تحققت
دالة Python من الناتج. الصفحة ذات نصوص مهربة وCSP يمنع اتصالات
الشبكة. لم يجر تحقق بصري داخل المتصفح؛ أداة المتصفح رفضت فتح رابط
الملف المحلي بسياسة URL. بقي التحقق البرمجي والتصدير المصطنع ناجحين.

## التدقيق

ثلاث مراجعات مستقلة شملت دورة الحالة والكشف والهوية والملخصات،
وربط الحكم بالتقرير، وحقن HTML/JavaScript، ومعنى النتائج الجزئية.
لكل ملاحظة مثبتة تفنيدان مستقلان؛ أصلحت النتائج مع اختبارات انحدار:

| الملاحظة | الإصلاح المثبت |
|---|---|
| الملخص المحفوظ قد يعيد حقولًا غير مصرح بها | حقول عددية مغلقة، أنواع صارمة، وربط بالقيم الفعلية للمحاولة |
| حذف أو تبديل البيان لا يوقف كائنًا مفتوحًا | قراءة البيان داخل القفل في كل عملية، ومقارنة بصمته للتمييز بين bool وint |
| ملخص مغلق قد يستبعد حالة لم تُكشف | كل حالة غائبة عن درجات محاولة مغلقة يجب أن تكون ضمن الكشف الدائم |

بقيت الملخصات التاريخية الصحيحة قابلة للاسترجاع بعد كشف لاحق؛
والقفل بين عمليتين يحمي دورة الحالة. فشل الكتابة قبل الاستبدال لا
ينشر كشفًا أو خصمًا، والفشل بعده يستأنف الأثر المحفوظ.

## الحدود والعمل المعلق

- **لا بنك قبول مستقل فعلي حتى الآن.** البنك العلني أو الذي يراه وكيل التأليف يبقى تطويريًا؛ لا يصير محجوبًا بتغيير اسمه.
- **لا مراجعة بشرية مستلمة حتى الآن.** الصفحة جاهزة للمالك أو مراجع يختاره؛ هوية المراجع إقرار محلي غير مصادق عليه.
- ربط مشغّل البنك المستقل وأجوبته بأحكامه الفعلية سيُستكمل بعد ورود البنك؛ مكتبة حفظ الدرجات لا تثبت بنفسها تنفيذ نموذج أو إنسان.
- لا تمنع بصمة الحالة مالك القرص من إعادة كتابة المخزن كله أو إرجاع نسخة قديمة؛ هذا الحد معلن، ولا توجد دعوى عزل نظامي.
- مراجعة الأجوبة التطويرية لا تحقق استقلال القبول. `release_ready=false` يبقى في المخرجات.

م٩ لم يبدأ: بوابة `ROADMAP.md` تتطلب جاهزية مجموعة قبول مستقلة،
ومجموعة كهذه غير متاحة في سياق التطوير الحالي. النتيجة المنجزة هنا
هي أدوات ومادة مراجعة ملموسة، لا إغلاق شكلي للمرحلة.
