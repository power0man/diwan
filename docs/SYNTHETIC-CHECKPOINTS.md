# لقطات جلسات مصطنعة بعقد خاص — تجربة تشغيل مغلقة

المسألة #264: `workspace_tools/synthetic_checkpoints.py` مستقل عن واجهة اللقطات
العامة وموافقاتها في `checkpoints.py`؛ لا يغيّر سلوكها أو سياساتها.

`commit_synthetic_checkpoint(archive, expected_sha256, expected_scope, store)`
يقبل نسخة مصدّرة والتطبيق مغلق. `expected_scope` بايتات عقد259 المحفوظ لدى
المشغل خارج جذر التشغيل المؤقت؛ يطابق عقد الأرشيف حرفيًا قبل أي نداء للمخزن.
كل الجلسات نصية أو وكيلة عادية جديدة منذ الميلاد، `internal` مع ربط العقد،
والمحتوى `synthetic_only` والاستدلال محلي. تصنيف `internal` وحده لا يجيز الرفع.
الجلسة المحلية أو غير المصنفة، والملفات المرفوعة، وأنماط الجلسات الأخرى مرفوضة.
مصدر النص المصطنع مسؤولية المشغل الموثوق؛ لا مصنّف آليًا ولا استقبال ملفات مالك.

تحت `store.exclusive()` يربط `bind_scope(raw)` الفرع الدائم بالعقد والهدف الفعلي،
أو يطابق ربطه السابق. الإيصال `diwan_synthetic_checkpoint` يحمل هوية المساحة
وبصمة العقد والهدف الكامل مع بصمات الأرشيف والمنسيات وسلسلة الإيصالات.
حدّ الإيصال 4096 بايت مثل رأس موصل Hub؛ يُفحص أكبر شكل ممكن قبل أي نداء،
فيرفض العقد الطويل حتى لو كانت بايتات عقد الإنشاء نفسه ضمن حده الأكبر.
تتبع
الكتابة قراءة تحقق ثم CAS ثم قراءة الرأس والخروج الناجح من lease. لا تعلن
الدالة نجاحًا قبل ذلك. فشل بدء CAS أو تأكيده أو تحرير lease بعده غير محسوم:
قد تقدم الرأس، فلا إعادة تلقائية أو إنشاء namespace بديل.

`restore_synthetic_checkpoint(store, destination, expected_scope,
receipt_sha256=None)` يستعمل `exclusive(require_bound=True)` ثم
`verify_scope(raw)`؛ لا ينشئ ربط فرع عند غيابه. الرأس والسلف والأرشيف كلها
تطابق الهوية نفسها. استعادة السلف تستخدم أحدث سجل نسيان ملتزم، ولا تتراجع
إلى سجل قديم عند تعذر قراءة الأحدث. يظل التطبيق مغلقًا حتى نجاح الاستعادة
والخروج من lease؛ الوجهة الموجودة مرفوضة. يحتفظ المشغل بالعقد المتوقع مستقلًا
ولا يتبنى عقدًا وصل من المخزن لمجرد صحة بصمته.

حدود القبول: اختبارات بمزوّد وموصل مصطنعين فقط، بينها كاتب وقارئ بعمليتين
جديدتين وجذر مصدر أُزيل؛ لا ادعاء عن استدامة خدمة منشورة أو حفظ كل رسالة.
الموصل الحقيقي ملزم بعقد ربط الفرع وبخصوصيته وCAS/lease؛ التطبيق له كاتب واحد.
حجز الفرع المحلي لا يكفي بعد فقد القرص، والقفل المشغول بعد موت حامله يرفض؛
لا انتهاء صلاحية أو فك قفل أو مصالحة تلقائية هنا. لم تُمح بايتات التدقيق أو
النسخ القديمة؛ النسيان يمنع إعادة الاستخدام وفق عقد الاستعادة القائم.
