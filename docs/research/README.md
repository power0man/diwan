# البحث المعتمد — بوابة التحقق

هذا المجلد لا يستقبل إلا **حصيلة مدقَّقة**. القناة:

1. هرمس (وظيفة `un-law-scout` اليومية) يبحث ويكتب مادةً خامًا في
   `~/diwan-work/hermes-research/findings/`.
2. الجلسة المحلية تدقّق البنود من **المصادر الأولية** (treaties.un.org،
   ‏imo.org، ‏ilo.org) — تدقيقًا عدائيًّا لا استئناسيًّا.
3. المؤكد فقط يدخل هنا، بحكمه (مؤكد/مصحَّح) ومصادره؛ وما لم يُدقَّق بعد
   يُدرج تحت «قيد التحقق» صراحةً ولا يُستشهد به.

القاعدة الحاكمة: **ادعاءات أقوى من أدلتها تُرَدّ** — وكل بند بتاريخه
ومصدره الأولي، والفشل في التحقق يُذكر لا يُخفى.
