# تجربة التفريغ العربي المحلية — ٣ أكتوبر ٢٠٢٦

Refs #281 و#51 و#42. التجربة تضيف طريق سطر أوامر اختياريًا، ولا تفعّل
`transcribe_audio` في الحلقة الوكيلة أو الواجهة. قبول غ١٠ لم يكتمل؛ بنك الكلام
الحقيقي المطلوب في `docs/MEDIA-BANK.md` لم يُجمّد، ولا اختبار TTS أو لهجات.

## التنفيذ

`multimodal/local_asr.py` يشغّل whisper.cpp المحلي مرة واحدة على نسخة مؤقتة
من WAV اختاره المستخدم صراحةً: PCM أحادي، 16-bit، 16kHz، حتى ثماني ثوانٍ.
يستعمل عقد `multimodal/codec.py` القائم، ولا يحوّل صيغة المدخل تلقائيًا.
العربية `ar` مثبتة، والتشغيل CPU فقط بخيطين افتراضيًا (1–4)، والمهلة
1–120 ثانية، ولا إعادة نداء أو تنزيل تلقائي. الناتج نصٌّ لا تفويض تنفيذ.
الصوت والناتج المؤقتان يُحذفان عند انتهاء العملية أو فشلها؛ الأداة لا تنشئ
جلسة أو سجل ذاكرة. CLI يطبع التفريغ؛ حفظ stdout مسؤولية مستدعيه.

يقدّم المشغّل مساري تنفيذ وأوزان موثوقين مطلقين وبصمتي SHA256. تُفحص
البصمتان قبيل الاستدعاء. ليست هذه عزلةً أمنيةً ضد برنامج خبيث أو استبدال
الملفات أثناء الاستدعاء؛ ولا تبصم المكتبات الديناميكية معه. لا تضع ملفات
المالك أو الأوزان أو ثنائيات التنفيذ في Git. النتيجة تحمل دائمًا
`release_ready=false`، وأخطاء التهيئة والمهلة والعملية والناتج حالات صريحة.

```sh
.venv/bin/python tools/transcribe_audio.py \
  --file /absolute/path/selected.wav \
  --binary /absolute/path/whisper-cli --binary-sha256 SHA256 \
  --model /absolute/path/ggml-small.bin --model-sha256 SHA256 \
  --threads 2 --timeout 120
```

## القياس وحدوده

بُني [whisper.cpp v1.9.4](https://github.com/ggml-org/whisper.cpp/tree/v1.9.4)
محليًا دون Metal أو CURL أو خادم، من مصدر ببصمة
`57e280cee375ab02425b806ad5146b99f6eb9357e3c2b31357c8a6af2e2e44ae`.
الأوزان [small متعددة اللغات](https://huggingface.co/ggerganov/whisper.cpp/tree/5359861c739e955e79d9a303bcbc70fb988958b1)
ببصمة `1be3a9b2063867b937e64e2ec7483364a79917e157fa98c5d94b5c1fffea987b`.
لا تتطلب التجربة حسابًا أو رمزًا، ولا تختار محرك غ١٠ النهائي في الخطة.

العينة ست جمل مؤلفة للتجربة، نُطقت محليًا بصوت macOS Majed بسرعة 160،
وملف صمت رقمي من ثانيتين. جُمّدت بايتات الملفات وبصماتها قبل المقارنة.
المخرجات والتوقيتات والمرجع وبصمات مصدر الأدوات في
`docs/probe/arabic-whisper-pilot-20261003.json`؛ ملفات الصوت تبقى محلية.

| التشخيص | النتيجة المصطنعة |
|---|---|
| استدعاءات الكلام | 6/6 مكتملة؛ لا خطأ عملية |
| WER للكلام | 4/33 = 12.12% |
| CER للكلام | 7/184 = 3.80% |
| الصمت قبل الحارس | هلوسة: «اشتركوا و اشتركوا و اشتركوا.» |
| الصمت بعد الحارس | `no_speech`؛ لا استدعاء للنموذج |

`evaluation/speech_pilot.py` يحسب مسافة تحرير الكلمات والمحارف ويجمع
المقامات على مستوى العينة، ولا يحوّل أعطال التشغيل إلى أخطاء تعرف أو نجاحات.
التطبيع هو القائم في بنك الوسائط: NFKC وحذف الحركات والتطويل وتوحيد
المسافات، دون إزالة علامات الترقيم أو مساواة الهمزات والتاء المربوطة.
نسبة الخطأ قد تتجاوز 100% عند كثرة الإدراج. الصمت له عداد هلوسة منفصل.

الحارس يعترض PCM الصفري كله فقط؛ لا يدّعي كشف الكلام أو معالجة الضجيج
والصمت غير الصفري. دليل خط الأساس محفوظ، وحُسبت النتائج بعد الحارس على
الملفات نفسها. تبقى هلوسة النموذج في الصمت خطرًا غير محلول للكلام الحقيقي.

هذه عينة صغيرة بصوت اصطناعي واحد، ليست دليلًا على اللهجات أو ضجيج الميكروفون
أو Common Voice. بلوغ الأرقام المصطنعة عتبتَي البنك لا يجيز قبول غ١٠.
قبل التفعيل يلزم تجميد عينة حقيقية مرخصة وقياسها بالعتبات المسجلة، ثم ربط
محكوم ومراجعة مستقلّة. لم يُستعمل صوت المالك، ولم تُنشر بياناته أو يُغيّر
مسار UI أو staging أو نشر HF/Cloudflare.
