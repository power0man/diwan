# ديوان

ديوان مشروع **مساعد عام محوره العربية**: للحوار والاستدلال والكتابة
والترجمة والبرمجة والعمل بالمعرفة والملفات والأدوات. الرؤية في
[VISION.md](docs/VISION.md)، والخارطة في [ROADMAP.md](docs/ROADMAP.md).

## التشغيل السريع (v0.1 «ديوان على جهازك»)

```sh
uv sync                                  # بايثون ≥ 3.11؛ الاعتمادياتُ من uv.lock المقفول، وفيها CAMeL Tools للجذور (ق٥٥؛ torch للمعالج على لينكس، ك٣٣)
uv run camel_data -i morphology-db-msa-r13   # قاعدةُ CAMeL الصرفية، مرّةً واحدة
ollama pull qwen3.5:9b                   # المحرّكُ المعتمَد بالقياس (ق٥٤؛ providers/ollama.py::DEFAULT_MODEL)
uv run python tools/launch_check.py      # فحصُ الدخان: البيئة، وCAMeL، والمحرّك، وجولةٌ وكيلة، وعقدةُ السياسات إن وُضع المتن، والواجهة
uv run python tools/serve_ui.py          # الواجهةُ المحلية على http://127.0.0.1:8765
```

فحصُ الدخان يخرج 0 حين يعمل كلُّ شيء، و3 حين يتعذّر شيءٌ بحدٍّ معلن (لا CAMeL، لا محرّك، لا متن) ويسمّيه،
و1 عند عطب. الرخصةُ Apache-2.0 (`LICENSE`)، والخطةُ في [LAUNCH-PLAN-20260925.md](docs/LAUNCH-PLAN-20260925.md).

**في حاوية (ج٦):** `docker build -t diwan .` تثبيتٌ بأمرٍ واحد من القفل المجمَّد، وقاعدةُ CAMeL داخل الصورة.
و`docker run --rm diwan` يشغّل فحصَ الدخان، و`docker run --network host diwan python tools/serve_ui.py` يشغّل
الواجهة على لينكس. والمحرّكُ Ollama على المضيف خارج الحاوية. ومهمّةُ `container-smoke` تبني الصورة
على المشغّل المستضاف، وتشغّل الفحصَ بلا شبكة، فتنتظر الخروج 3 بخطواتٍ مسمّاة.

المبني اليوم نواة تحكم تمر عبرها نداءات النموذج، ومخزن معرفة بحقوق
وإسناد، وعقد تخصصية وخدمات مركبة. أضيفت محادثة نصية محلية متعددة
الجولات وCLI تجريبي في م٩؛ [دليل التشغيل](docs/CHAT.md).
واجهة م١١ المحلية تجمع المشروعات والمحادثات والملفات والتفضيلات
ومراجعة المسودات؛ [تشغيل الواجهة](docs/DAILY-UI.md)،
[نتائج التحقق وحدودها](docs/M11-ACCEPTANCE.md).
أضيف إدخال PNG وWAV محليين في م١٢، وإجابة نصية: [التشغيل](docs/MEDIA.md)
و[دليل التحقق](docs/M12-ACCEPTANCE.md).

م١٣-أ تضيف [النسخ والاستعادة المحلية](docs/BACKUP.md) وفحص النشر
قبل التغيير؛ [الدليل والبوابات المفتوحة](docs/M13A-ACCEPTANCE.md).

## ما ليس مثبتًا — بصراحة

- **الجودة العامة غير مثبتة**: التشخيص العلني الأول والفحوص الحتمية
  المحدودة لا يثبتان صحة المعنى أو التعميم. المراجعة الآلية متعددة الأنظمة والقبول
  المستقل والمقارنة العادلة ما زالت مطلوبة. و`complete` في البحث
  يصف استرجاع الخطة، لا كفايتها لتلبية طلب المستخدم.
- **«النواة العربية» أقلُّ مما يوحي الاسم**: بحثٌ نصيٌّ في المعاجم،
  ومطابقةُ مصطلحٍ بالسوابق والتشكيل، ومحلل صرفي وقواعد نحوية محدودة؛
  هذه المكونات لا تثبت امتلاك فهم لغوي عام.
- **المخزن ضيّق**: لوائح بحرية سعودية — أي قياسٍ عليه لا يعمّم.
- **حقوق التوزيع محدودة**: سُحب إسقاط اللوائح السعودية وفق ق٤٨ — عائقٌ ترخيصي لا
  هندسي.
- **الجاهزية المستمرة**: يصلح لتجارب محلية محكومة؛ الميزانية الدائمة
  عبر التشغيلات وإدارةُ التدوير مؤجلتان.

## البنية

`core/` النواة (تفرض ولا تفهم) · `nodes/` العقد التخصصية ·
`services/` التراكيب · `conversation/` الجلسات · `tools/` الأدوات · `corpus/` المخازن ·
`docs/` الوثائق الحاكمة (`ARCHITECTURE.md` المعمارية، `DECISIONS.md`
القرارات المسبَّبة، `SESSION-HANDOFF.md` الحالة).

للتشخيص المحلي بالمزود المثبت، عيّن هويته محليًا ثم شغّل:

```sh
.venv/bin/python tools/evaluate_capabilities.py --model "$DIWAN_EVAL_MODEL"
```

الأجوبة والسجل تحت `var/capabilities/` خارج git. تكرار الإعداد نفسه
يعيد النتائج المحفوظة. رمز خروج 0 يعني اكتمال جمع الأجوبة فقط؛ المرجع
والفحوص لا يرسلان للنموذج، و`manual_review=not_required_q49` و`release_ready=false`
يبقيان صريحين. راجع [بروتوكول التقييم](docs/CAPABILITY-EVALUATION.md).

للمراجعة الجديدة استعمل `tools/review_automatically.py` على أثر ومعيار
مجمدين، بنموذجين محليين مختلفي العائلة والبصمة. اختلاف الآراء وتعذر
المراجعة يبقيان ظاهرين. `tools/review_capabilities.py` مسار بشري
تاريخي اختياري، لا شرط قبول. ولا تتحول الحالات العلنية إلى بنك محجوب.

للمحادثة المحلية، عيّن هوية النموذج وبصمته محليًا كما في `docs/CHAT.md`:

```sh
.venv/bin/python tools/chat.py --session daily chat
```

يحفظ السياق النصي الجديد تحت `var/cli-chat/`، ويعيد الجولة المسجلة دون نداء جديد.
أجوبة هذا المسار عامة غير متحققة؛ الملفات والتفضيلات في مسار مساحة العمل المنفصل.
`acceptance_m9.py` يختبر الآلية مصطنعًا، و`--live` يجمع دليل تشغيل
حقيقي منفصل. حدود الإنجاز في [M9-ACCEPTANCE.md](docs/M9-ACCEPTANCE.md).

**م١٠ التجريبية:** ملفات نصية مختارة وتفضيلات تحفظ صراحة، واقتراحات
ملفات قابلة للمراجعة قبل التطبيق إلى ملفات جديدة فقط. لا تنفيذ
مستقل للنموذج. راجع [دليل مساحة العمل](docs/WORKSPACE.md) و
[دليل م١٠](docs/M10-ACCEPTANCE.md): عند إنجاز تلك الدفعة 947 اختبارًا، وقبول مصطنع22/22
وحي13/13؛ قبول الجودة المستقل ما زال معلقًا، وبوابته الحالية آلية وفق ق٤٩.
