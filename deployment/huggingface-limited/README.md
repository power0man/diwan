# ديوان الخاص على Hugging Face CPU Basic

هذا تغليف تشغيل محدود مستقل عن الماك، وليس تكافؤًا مع خدمة الأدوات الكاملة.
مصدر المنتج المثبت هو `9e62b7561e9e8931d16a02cfba65459c25a8501a`، ومحركه
`qwen3.5:9b` ببصمة `6488c96fa5faab64bb65cbd30d4289e20e6130ef535a93ef9a49f42eda893ea7`.

`prepare.py` يحتاج Python 3.12+ ويصدر الملفات المتتبعة المسموح بها من Git فقط.
لا ينسخ مساحة تشغيل أو بيانات مالك أو بنك قياس. يضيف شريط الحدود إلى نسخة HTML
ويكتب `SOURCE.json` ببصمات كل ملفات الحزمة. شيفرة المنتج الأخرى تبقى كما هي.

المساحة يجب أن تبقى **private**؛ تسجيل الدخول إلى حساب مالكها مطلوب، والرابط المباشر
للتطبيق يُفتح في صفحة مستقلة لأن ديوان يرفض تضمين الصفحة في إطار من أصل آخر.
لا توضع مفاتيح المنصة في عنوان الصفحة أو صورة Docker أو الشيفرة.

الحاوية تستضيف Ollama على loopback وديوان على loopback خلف nginx. الوكيل يحافظ على
Host وOrigin، ويسقط Authorization قبل التطبيق؛ تبقى حراس CSRF والتنقل والأصول في
ديوان كما هي. لا منفذ عام لـOllama. تعيين الأصل العام مطابق لاسم مساحة HF فقط.

أدوات Docker والتحليل والبحث والوسائط غير مفعلة: لا socket ولا إيصالات تفعيل، وقد
رفضت بيئة HF الفعلية إنشاء user/network namespaces. لا تشغيل بديل غير معزول.
أدوات الملفات النصية والمحادثة متاحة ضمن مساحة مؤقتة. لم يثبت حفظ مساحة المنتج
عبر إعادة البناء؛ اختبار بقاء sentinel في bucket منفصل ليس قبول استعادة للمنتج.

المعالج المجاني بطيء: الطلب الأول للمنتج انتهت مهلته عند 120 ثانية. `cloud_app.py`
يحدد القيمة الافتراضية لإنشاء الجلسات فقط بـ300 ثانية باستخدام `functools.partial`
على صنفي الجلسة اللذين يستخدمهما `LocalApp`. تُسجل القيمة في manifest الطبيعي؛
تغلبها قيمة أي جلسة محفوظة صراحة. سقف مزود الاستدلال القائم 300 ثانية لا يتغير.
أثبت فحص محلي مصطنع إنشاء مساحة عامة بهذه القيمة ثم إعادة فتح جلستها.

من الجهاز المجهز، تُنشأ الحزمة بمجلد إخراج جديد:

```sh
python3.12 deployment/huggingface-limited/prepare.py /tmp/diwan-hf-package
```

ثم تُرفع إلى مساحة Docker **خاصة قائمة** عبر HF CLI المصادق، على CPU Basic فقط.
لا يُطلب تغيير العتاد أو فوترة أو توسيع صلاحيات. قبل الرفع يجب التأكد من أن
المجلد لا يحوي `__pycache__` أو نواتج اختبارات محلية وأن `SOURCE.json` يطابق الحزمة.
بعده يلزم قبول فعلي للمصادق والمجهول وحراس HTTP وجواب المنتج، لا الاكتفاء بـRUNNING.
